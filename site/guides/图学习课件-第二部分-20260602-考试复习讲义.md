# 图学习课件_第二部分_20260602：按课件顺序重写的考试复习讲义

这份讲义会尽量按你读课件时真正需要的顺序来讲。

---

## 先说整份课件到底在解决什么问题

这一份课件要解决的是：**当数据本身是一张图时，模型怎样同时利用节点特征和节点之间的关系。**

图学习最重要的不是某个模型名字，而是“对象之间有边，边决定信息怎么传”。GNN 的很多方法都可以看成邻居信息的聚合和更新。

读的时候先抓这条线：**节点/边 -> 邻接矩阵 -> 图任务类型 -> 随机游走或表示学习 -> GCN/GAT 等图神经网络。**

## 开始按课件一点一点讲

## 第 1 部分：从序列建模瓶颈到 Transformer

### 这一节先不要急着背

这一节可以按 **Transformer -> RNN -> Seq2Seq -> Attention -> 注意力机制** 的顺序读。第一个概念通常是入口，后面的概念要么是在补结构，要么是在解释训练时会遇到的问题。

### 1. 先讲 Transformer

先用最普通的话说，**Transformer** 就是：以注意力为核心的序列模型，用多头注意力、前馈网络、残差和归一化堆叠编码器/解码器。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考编码器/解码器结构、多头注意力和位置编码。

如果按课件顺序串起来，可以这样看：**前面的概念 -> Transformer -> RNN**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**Transformer 核心：Attention + FFN + 残差 + Norm + 位置编码。**

这里最容易错的是：Transformer 不依赖 RNN 的逐步递归来建模序列。

### 2. 先讲 RNN

先用最普通的话说，**RNN** 就是：按时间步处理序列，用隐藏状态把前面信息传到后面。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考隐藏状态、序列建模、梯度消失/爆炸。

如果按课件顺序串起来，可以这样看：**Transformer -> RNN -> Seq2Seq**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**当前输出依赖当前输入和上一时刻隐藏状态。**

这里最容易错的是：RNN 不是一次性把所有时间步完全独立处理。

### 3. 先讲 Seq2Seq

先用最普通的话说，**Seq2Seq** 就是：编码器把输入序列压成表示，解码器再生成输出序列，常用于翻译、问答等序列到序列任务。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考 Encoder-Decoder 结构、Teacher Forcing 和注意力机制为何被引入。

如果按课件顺序串起来，可以这样看：**RNN -> Seq2Seq -> Attention**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**Seq2Seq = Encoder + Decoder。**

这里最容易错的是：普通 Seq2Seq 容易受固定长度上下文瓶颈影响。

### 4. 先讲 Attention

先用最普通的话说，**Attention** 就是：根据相关性分配权重，再对信息加权汇总。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考 Q/K/V、权重、softmax、上下文向量。

如果按课件顺序串起来，可以这样看：**Seq2Seq -> Attention -> 注意力机制**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**Attention = 按相关性加权关注。**

这里最容易错的是：Attention 不是简单平均。

### 5. 先讲 注意力机制

先用最普通的话说，**注意力机制** 就是：根据 Query 与 Key 的匹配程度，给 Value 分配权重并加权求和。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考 Q/K/V 含义、注意力权重、上下文向量计算流程。

如果按课件顺序串起来，可以这样看：**Attention -> 注意力机制 -> 梯度消失**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**Attention(Q,K,V)=softmax(QK^T/sqrt(d_k))V。**

这里最容易错的是：注意力不是简单平均，而是按相关性加权。

### 6. 先讲 梯度消失

先用最普通的话说，**梯度消失** 就是：反向传播经过很多层或很多时间步时，梯度可能不断变小，导致前面层或早期时间步很难学到东西。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考深层网络/RNN 为什么训练困难，以及 LSTM、GRU、残差连接如何缓解。

如果按课件顺序串起来，可以这样看：**注意力机制 -> 梯度消失 -> 梯度爆炸**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**多个小于 1 的因子连乘，会让梯度趋近 0。**

这里最容易错的是：梯度消失不是过拟合；它是参数难以有效更新的问题。

### 7. 先讲 梯度爆炸

先用最普通的话说，**梯度爆炸** 就是：梯度在反向传播中变得过大，使参数更新剧烈，训练损失可能震荡或变成 NaN。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考梯度裁剪为什么能缓解 RNN 训练不稳定。

如果按课件顺序串起来，可以这样看：**梯度消失 -> 梯度爆炸 -> LSTM**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**梯度裁剪限制梯度范数，防止更新步子过大。**

这里最容易错的是：Dropout 主要缓解过拟合，不是解决梯度爆炸的标准答案。

### 8. 先讲 LSTM

先用最普通的话说，**LSTM** 就是：通过输入门、遗忘门、输出门和细胞状态保存长期信息。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考门控作用，以及为什么能缓解长序列梯度问题。

如果按课件顺序串起来，可以这样看：**梯度爆炸 -> LSTM -> 归一化**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**LSTM：输入门、遗忘门、输出门、细胞状态。**

这里最容易错的是：不要漏掉细胞状态是 LSTM 的关键通道。

### 9. 先讲 归一化

先用最普通的话说，**归一化** 就是：把数值缩放到较统一范围，例如图像像素从 0-255 缩放到 0-1。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考图像预处理为什么要缩放像素值。

如果按课件顺序串起来，可以这样看：**LSTM -> 归一化 -> Query**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**图像常先把像素值缩放到 0-1。**

这里最容易错的是：归一化不等于 BatchNorm，前者多是输入预处理。

### 10. 先讲 Query

先用最普通的话说，**Query** 就是：Query 表示当前位置主动提出的查询，用来和 Key 计算匹配度。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考 Q 与 K 点积得到注意力分数。

如果按课件顺序串起来，可以这样看：**归一化 -> Query -> 后面的概念**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**Query 问：我要找什么信息？**

这里最容易错的是：不要把 Query 和 Value 的角色混淆。

### 这一节最后怎么记

- **Transformer**：Transformer 核心：Attention + FFN + 残差 + Norm + 位置编码。
- **RNN**：当前输出依赖当前输入和上一时刻隐藏状态。
- **Seq2Seq**：Seq2Seq = Encoder + Decoder。
- **Attention**：Attention = 按相关性加权关注。
- **注意力机制**：Attention(Q,K,V)=softmax(QK^T/sqrt(d_k))V。
- **梯度消失**：多个小于 1 的因子连乘，会让梯度趋近 0。

### 本节检查题

1. **选择题：关于 Transformer，下列说法错误的是：**
   A. 以注意力为核心的序列模型，用多头注意力、前馈网络、残差和归一化堆叠编码器/解码器。
   B. Transformer 核心：Attention + FFN + 残差 + Norm + 位置编码。
   C. 常考编码器/解码器结构、多头注意力和位置编码。
   D. Transformer 必须依赖 RNN 的递归结构处理序列。

   **答案：D。** A、B、C 都能和课件里的 Transformer 对上；D 是把概念说反或放错位置。

2. **填空题：** RNN 的复习重点不是只写名称，而是写清它的作用：____。

   **参考答案：** 按时间步处理序列，用隐藏状态把前面信息传到后面。

3. **简答题：为什么考试里不能只背 Seq2Seq 的定义？**

   **参考答案：** 因为 Seq2Seq 在课件中有明确的位置和作用：编码器把输入序列压成表示，解码器再生成输出序列，常用于翻译、问答等序列到序列任务。 答题时还要补出它通常怎么考：常考 Encoder-Decoder 结构、Teacher Forcing 和注意力机制为何被引入。 最后要避开这个误区：普通 Seq2Seq 容易受固定长度上下文瓶颈影响。

4. **辨析题：请区分 Transformer 和 Attention。**

   **参考答案：** Transformer：以注意力为核心的序列模型，用多头注意力、前馈网络、残差和归一化堆叠编码器/解码器。；Attention：根据相关性分配权重，再对信息加权汇总。。答题时先判断它们分别处在数据、结构、训练还是输出环节。

## 第 2 部分：混合专家模型（MOE）

### 这一节先不要急着背

这一节先集中理解 **Softmax**。不要一上来背定义，先问：课件为什么在这里讲它？它补上了前面哪一个问题？

### 1. 先讲 Softmax

先用最普通的话说，**Softmax** 就是：把一组分数转成和为 1 的概率分布，常用于多分类或注意力权重。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考多分类输出、注意力权重为什么能加权求和。

考试写到这里，最稳的一句话是：**Softmax 输出非负且总和为 1。**

这里最容易错的是：Softmax 是对一组数整体归一化，不是逐个独立压缩。

### 这一节最后怎么记

- **Softmax**：Softmax 输出非负且总和为 1。

### 本节检查题

1. **选择题：关于 Softmax，下列说法错误的是：**
   A. 把一组分数转成和为 1 的概率分布，常用于多分类或注意力权重。
   B. Softmax 输出非负且总和为 1。
   C. 常考多分类输出、注意力权重为什么能加权求和。
   D. Softmax 输出不需要总和为 1。

   **答案：D。** A、B、C 都能和课件里的 Softmax 对上；D 是把概念说反或放错位置。

## 第 3 部分：给予示例的Prompt

### 这一节先不要急着背

这一节可以按 **Dropout -> Adam** 的顺序读。第一个概念通常是入口，后面的概念要么是在补结构，要么是在解释训练时会遇到的问题。

### 1. 先讲 Dropout

先用最普通的话说，**Dropout** 就是：训练时随机丢弃一部分神经元，迫使网络不要过度依赖某些特征。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考训练阶段启用、推理阶段关闭，以及它缓解过拟合。

如果按课件顺序串起来，可以这样看：**前面的概念 -> Dropout -> Adam**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**Dropout：训练随机失活，推理正常使用。**

这里最容易错的是：Dropout 不是提高模型容量，而是正则化。

### 2. 先讲 Adam

先用最普通的话说，**Adam** 就是：结合动量和自适应学习率思想，为不同参数调整更新幅度。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常和 SGD、Momentum、RMSProp 对比优化器特点。

如果按课件顺序串起来，可以这样看：**Dropout -> Adam -> 后面的概念**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**Adam = 一阶动量 + 二阶矩估计。**

这里最容易错的是：Adam 方便但不等于一定泛化最好，仍需调学习率等超参数。

### 这一节最后怎么记

- **Dropout**：Dropout：训练随机失活，推理正常使用。
- **Adam**：Adam = 一阶动量 + 二阶矩估计。

### 本节检查题

1. **选择题：关于 Dropout，下列说法错误的是：**
   A. 训练时随机丢弃一部分神经元，迫使网络不要过度依赖某些特征。
   B. Dropout：训练随机失活，推理正常使用。
   C. 常考训练阶段启用、推理阶段关闭，以及它缓解过拟合。
   D. Dropout 推理阶段仍要随机丢弃神经元。

   **答案：D。** A、B、C 都能和课件里的 Dropout 对上；D 是把概念说反或放错位置。

2. **填空题：** Adam 的复习重点不是只写名称，而是写清它的作用：____。

   **参考答案：** 结合动量和自适应学习率思想，为不同参数调整更新幅度。

## 第 4 部分：DeepSeek R1

### 这一节先不要急着背

这一节先集中理解 **Epoch**。不要一上来背定义，先问：课件为什么在这里讲它？它补上了前面哪一个问题？

### 1. 先讲 Epoch

先用最普通的话说，**Epoch** 就是：训练集被模型完整看过一遍，叫一个 epoch。一个 epoch 内通常包含很多个 batch 更新。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考 Epoch、Batch、Iteration 的区别，或判断训练轮数增加对欠拟合/过拟合的影响。

考试写到这里，最稳的一句话是：**1 个 Epoch = 全部训练样本被用过一遍。**

这里最容易错的是：Epoch 不是一次参数更新；一次更新通常对应一个 batch。

### 这一节最后怎么记

- **Epoch**：1 个 Epoch = 全部训练样本被用过一遍。

### 本节检查题

1. **选择题：关于 Epoch，下列说法错误的是：**
   A. 训练集被模型完整看过一遍，叫一个 epoch。一个 epoch 内通常包含很多个 batch 更新。
   B. 1 个 Epoch = 全部训练样本被用过一遍。
   C. 常考 Epoch、Batch、Iteration 的区别，或判断训练轮数增加对欠拟合/过拟合的影响。
   D. 一个 epoch 就是一次参数更新。

   **答案：D。** A、B、C 都能和课件里的 Epoch 对上；D 是把概念说反或放错位置。
