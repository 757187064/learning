## 先说整份课件到底在解决什么问题

这一份课件要解决的是：**最基础的神经网络到底怎么从输入走到预测，再从错误走回参数更新。**

多层感知机不是只背几层 Linear，它的重点是把“线性变换、激活函数、损失函数、反向传播、优化器”连成一条训练流程。

读的时候先不要被代码吓到。你只需要先抓住：**前向传播得到预测，损失函数衡量错多少，反向传播算梯度，优化器改参数。**

## 开始按课件一点一点讲

## 第 1 部分：第二章 神经网络训练流程

### 这一节先不要急着背

这一节可以按 **自动微分 -> 梯度下降 -> 计算图** 的顺序读。第一个概念通常是入口，后面的概念要么是在补结构，要么是在解释训练时会遇到的问题。

### 1. 先讲 自动微分

先用最普通的话说，**自动微分** 就是：深度学习框架自动根据计算图计算梯度。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考 backward、grad、requires_grad 的关系。

如果按课件顺序串起来，可以这样看：**前面的概念 -> 自动微分 -> 梯度下降**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**自动微分帮你算梯度，不替你设计训练流程。**

这里最容易错的是：自动微分不是自动训练；还需要 loss.backward 和 optimizer.step。

### 2. 先讲 梯度下降

先用最普通的话说，**梯度下降** 就是：沿着损失函数下降最快的方向调整参数，让模型预测逐步变好。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考参数更新方向、学习率作用、训练循环位置。

如果按课件顺序串起来，可以这样看：**自动微分 -> 梯度下降 -> 计算图**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**参数更新方向通常与梯度相反。**

这里最容易错的是：梯度下降不是直接调准确率，而是通过损失函数和梯度改参数。

### 3. 先讲 计算图

先用最普通的话说，**计算图** 就是：把张量运算组织成图结构，框架据此追踪梯度计算路径。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考 PyTorch 动态计算图、requires_grad、detach 等概念。

如果按课件顺序串起来，可以这样看：**梯度下降 -> 计算图 -> 后面的概念**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**计算图记录运算关系，反向传播沿图求梯度。**

这里最容易错的是：不要在需要梯度的地方把计算图断开。

### 这一节最后怎么记

- **自动微分**：自动微分帮你算梯度，不替你设计训练流程。
- **梯度下降**：参数更新方向通常与梯度相反。
- **计算图**：计算图记录运算关系，反向传播沿图求梯度。

### 本节检查题

1. **选择题：关于 自动微分，下列说法错误的是：**
   A. 深度学习框架自动根据计算图计算梯度。
   B. 自动微分帮你算梯度，不替你设计训练流程。
   C. 常考 backward、grad、requires_grad 的关系。
   D. 自动微分只需要背名字，不需要知道它解决什么问题。

   **答案：D。** A、B、C 都能和课件里的 自动微分 对上；D 是把概念说反或放错位置。

2. **资料题：** 材料中出现 梯度下降，请判断它在本节属于数据、模型结构、训练优化还是输出目标，并说明理由。

   **参考答案：** 沿着损失函数下降最快的方向调整参数，让模型预测逐步变好。 答题时还要结合课件语境：常考参数更新方向、学习率作用、训练循环位置。

   **参考答案：** 因为 计算图 在课件中有明确的位置和作用：把张量运算组织成图结构，框架据此追踪梯度计算路径。 答题时还要补出它通常怎么考：常考 PyTorch 动态计算图、requires_grad、detach 等概念。 最后要避开这个误区：不要在需要梯度的地方把计算图断开。

## 第 2 部分：第二章 神经网络训练流程 / 第一节 梯度下降法

### 这一节先不要急着背

这一节可以按 **梯度下降 -> Epoch -> Batch -> 损失函数 -> 反向传播** 的顺序读。第一个概念通常是入口，后面的概念要么是在补结构，要么是在解释训练时会遇到的问题。

### 1. 先讲 梯度下降

先用最普通的话说，**梯度下降** 就是：沿着损失函数下降最快的方向调整参数，让模型预测逐步变好。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考参数更新方向、学习率作用、训练循环位置。

如果按课件顺序串起来，可以这样看：**前面的概念 -> 梯度下降 -> Epoch**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**参数更新方向通常与梯度相反。**

这里最容易错的是：梯度下降不是直接调准确率，而是通过损失函数和梯度改参数。

### 2. 先讲 Epoch

先用最普通的话说，**Epoch** 就是：训练集被模型完整看过一遍，叫一个 epoch。一个 epoch 内通常包含很多个 batch 更新。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考 Epoch、Batch、Iteration 的区别，或判断训练轮数增加对欠拟合/过拟合的影响。

如果按课件顺序串起来，可以这样看：**梯度下降 -> Epoch -> Batch**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**1 个 Epoch = 全部训练样本被用过一遍。**

这里最容易错的是：Epoch 不是一次参数更新；一次更新通常对应一个 batch。

### 3. 先讲 Batch

先用最普通的话说，**Batch** 就是：一次送入模型并一起计算损失的一组样本。它决定每次参数更新看到多少样本，也影响显存占用和训练稳定性。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考 batch size、mini-batch、epoch、iteration 的区别，也会结合张量形状中的 N 维度判断。

如果按课件顺序串起来，可以这样看：**Epoch -> Batch -> 损失函数**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**Batch 是一批样本；Epoch 是全训练集完整训练一遍。**

这里最容易错的是：Batch 不是序列长度；在 RNN 中常见形状里 N 是样本数，L 才是时间步长度。

### 4. 先讲 损失函数

先用最普通的话说，**损失函数** 就是：把模型预测和真实标签之间的差距变成一个可优化的数值，反向传播就是从损失开始计算梯度。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考输出层与损失函数的匹配，例如多分类常配 CrossEntropyLoss，二分类可配 BCEWithLogitsLoss。

如果按课件顺序串起来，可以这样看：**Batch -> 损失函数 -> 反向传播**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**损失函数告诉模型“错在哪里”，优化器负责“怎么改参数”。**

这里最容易错的是：不要把准确率当作训练损失；也不要把 BCE 和 CE 的适用场景混用。

### 5. 先讲 反向传播

先用最普通的话说，**反向传播** 就是：从损失函数出发，按链式法则把梯度传回各层参数。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考它和前向传播、损失函数、优化器的顺序关系。

如果按课件顺序串起来，可以这样看：**损失函数 -> 反向传播 -> 学习率**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**前向算预测，损失算错误，反向算梯度。**

这里最容易错的是：反向传播只负责算梯度，真正改参数的是优化器。

### 6. 先讲 学习率

先用最普通的话说，**学习率** 就是：控制每次参数沿梯度方向更新的步子大小。学习率太大容易震荡甚至发散，太小则收敛很慢。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考学习率过大/过小的训练现象，以及学习率调度的目的。

如果按课件顺序串起来，可以这样看：**反向传播 -> 学习率 -> 超参数**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**学习率决定更新步长。**

这里最容易错的是：学习率不是越大越好；也不是模型学到的参数。

### 7. 先讲 超参数

先用最普通的话说，**超参数** 就是：训练前人为设定的配置，如学习率、batch size、层数、dropout 比例。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考它和模型参数的区别。

如果按课件顺序串起来，可以这样看：**学习率 -> 超参数 -> 后面的概念**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**超参数先设定，模型参数训练中学习。**

这里最容易错的是：超参数不是通过反向传播直接学出来的参数。

### 这一节最后怎么记

- **梯度下降**：参数更新方向通常与梯度相反。
- **Epoch**：1 个 Epoch = 全部训练样本被用过一遍。
- **Batch**：Batch 是一批样本；Epoch 是全训练集完整训练一遍。
- **损失函数**：损失函数告诉模型“错在哪里”，优化器负责“怎么改参数”。
- **反向传播**：前向算预测，损失算错误，反向算梯度。
- **学习率**：学习率决定更新步长。

   B. 优化器负责执行参数更新。
   C. 常考 SGD、Momentum、RMSProp、Adam 的区别。
   D. 优化器只需要背名字，不需要知道它解决什么问题。

   **答案：D。** A、B、C 都能和课件里的 优化器 对上；D 是把概念说反或放错位置。

2. **资料题：** 材料中出现 损失函数，请判断它在本节属于数据、模型结构、训练优化还是输出目标，并说明理由。

   **参考答案：** 把模型预测和真实标签之间的差距变成一个可优化的数值，反向传播就是从损失开始计算梯度。 答题时还要结合课件语境：常考输出层与损失函数的匹配，例如多分类常配 CrossEntropyLoss，二分类可配 BCEWithLogitsLoss。

3. **简答题：为什么考试里不能只背 Dropout 的定义？**

   **参考答案：** 因为 Dropout 在课件中有明确的位置和作用：训练时随机丢弃一部分神经元，迫使网络不要过度依赖某些特征。 答题时还要补出它通常怎么考：常考训练阶段启用、推理阶段关闭，以及它缓解过拟合。 最后要避开这个误区：Dropout 不是提高模型容量，而是正则化。

4. **辨析题：请区分 优化器 和 梯度下降。**

   **参考答案：** 优化器：根据梯度和自身规则更新模型参数。；梯度下降：沿着损失函数下降最快的方向调整参数，让模型预测逐步变好。。答题时先判断它们分别处在数据、结构、训练还是输出环节。
