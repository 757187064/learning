## 先说整份课件到底在解决什么问题

这一份课件要解决的是：**图像不能简单当成一串数字直接丢给全连接网络。**

图像里有上下左右的位置关系，有局部纹理，也有边缘、角点、形状这些逐层组合出来的特征。CNN 的整个设计，就是为了让模型一层一层从局部看到整体。

所以读这份课件时，不要先背很多名词。先记住一条线：**图像有空间结构 -> 卷积保留局部结构 -> 池化压缩信息 -> 更深层网络组合高级特征。**

## 第 1 部分：第六章 CNN高级主题与应用

### 这一节先不要急着背

这一节可以按 **卷积 -> VGG -> ResNet -> LeNet -> GoogLeNet** 的顺序读。第一个概念通常是入口，后面的概念要么是在补结构，要么是在解释训练时会遇到的问题。

### 1. 先讲 卷积

先用最普通的话说，**卷积** 就是：用小窗口在图像局部滑动，对局部像素和卷积核权重相乘求和，提取边缘、纹理等局部特征。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考输出尺寸、卷积核/步长/填充的作用，以及 CNN 实际常用互相关。

如果按课件顺序串起来，可以这样看：**前面的概念 -> 卷积 -> VGG**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**输出尺寸：(输入尺寸 + 2P - K) / S + 1。**

这里最容易错的是：不要把 CNN 说成全连接；卷积核心是局部连接和参数共享。

### 2. 先讲 VGG

先用最普通的话说，**VGG** 就是：大量使用 3x3 小卷积核堆叠构建深层网络。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考小卷积核堆叠为什么能扩大感受野并减少参数。

如果按课件顺序串起来，可以这样看：**卷积 -> VGG -> ResNet**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**VGG：多层小卷积核堆叠。**

这里最容易错的是：不要把 VGG 的特点写成复杂多分支结构。

### 3. 先讲 ResNet

先用最普通的话说，**ResNet** 就是：用残差/跳跃连接让网络学习 F(x)+x，缓解深层网络退化和梯度传播困难。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考残差连接为什么能训练更深网络。

如果按课件顺序串起来，可以这样看：**VGG -> ResNet -> LeNet**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**ResNet 核心：y = F(x) + x。**

这里最容易错的是：残差连接不是单纯增加层数，而是改变信息和梯度路径。

### 4. 先讲 LeNet

先用最普通的话说，**LeNet** 就是：早期 CNN 结构，包含卷积、池化和全连接层，用于手写数字识别。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考 CNN 基本结构的历史代表。

如果按课件顺序串起来，可以这样看：**ResNet -> LeNet -> GoogLeNet**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**LeNet 展示了卷积 + 池化 + 分类的基本流程。**

这里最容易错的是：不要把 LeNet 写成现代超深残差网络。

### 5. 先讲 GoogLeNet

先用最普通的话说，**GoogLeNet** 就是：使用 Inception 模块的 CNN，通过多尺度卷积并行提取特征。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考 Inception 多分支、多尺度思想。

如果按课件顺序串起来，可以这样看：**LeNet -> GoogLeNet -> Inception**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**GoogLeNet 核心是 Inception。**

这里最容易错的是：不要把 GoogLeNet 与 VGG 的单一路径小卷积堆叠混淆。

### 6. 先讲 Inception

先用最普通的话说，**Inception** 就是：用不同大小卷积核和池化分支并行提取多尺度特征。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考多分支结构为什么能看不同尺度。

如果按课件顺序串起来，可以这样看：**GoogLeNet -> Inception -> 池化**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**Inception = 多分支多尺度特征提取。**

这里最容易错的是：Inception 不是单纯加深网络，而是多尺度并行。

### 7. 先讲 池化

先用最普通的话说，**池化** 就是：对局部区域做最大值或平均值汇总，降低空间尺寸并增强一定平移不变性。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考池化作用、是否有可学习参数、与卷积的区别。

如果按课件顺序串起来，可以这样看：**Inception -> 池化 -> 感受野**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**池化：降采样、压缩空间尺寸、保留显著信息。**

这里最容易错的是：池化不是全连接，也不是用来增加参数量。

### 8. 先讲 感受野

先用最普通的话说，**感受野** 就是：某一层一个神经元能看到原始输入图像的区域大小。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考层数、卷积核大小、步长如何影响感受野。

如果按课件顺序串起来，可以这样看：**池化 -> 感受野 -> 梯度消失**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**层越深，感受野通常越大；多层小卷积能逐步扩大感受野。**

这里最容易错的是：步长变大通常会让前一层对应感受野扩大，不是缩小。

### 9. 先讲 梯度消失

先用最普通的话说，**梯度消失** 就是：反向传播经过很多层或很多时间步时，梯度可能不断变小，导致前面层或早期时间步很难学到东西。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考深层网络/RNN 为什么训练困难，以及 LSTM、GRU、残差连接如何缓解。

如果按课件顺序串起来，可以这样看：**感受野 -> 梯度消失 -> 残差连接**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**多个小于 1 的因子连乘，会让梯度趋近 0。**

这里最容易错的是：梯度消失不是过拟合；它是参数难以有效更新的问题。

### 10. 先讲 残差连接

先用最普通的话说，**残差连接** 就是：把输入直接跨层加到输出上，形成 y=F(x)+x 的捷径。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考它为什么缓解深层网络退化和梯度传播困难。

如果按课件顺序串起来，可以这样看：**梯度消失 -> 残差连接 -> 后面的概念**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**残差连接给信息和梯度一条捷径。**

这里最容易错的是：残差连接不是简单增加参数量。

### 这一节最后怎么记

- **卷积**：输出尺寸：(输入尺寸 + 2P - K) / S + 1。
- **VGG**：VGG：多层小卷积核堆叠。
- **ResNet**：ResNet 核心：y = F(x) + x。
- **LeNet**：LeNet 展示了卷积 + 池化 + 分类的基本流程。
- **GoogLeNet**：GoogLeNet 核心是 Inception。
- **Inception**：Inception = 多分支多尺度特征提取。

## 第 2 部分：第六章 CNN高级主题与应用 / 第1节 CNN神经网络训练完整实践

### 这一节先不要急着背

这一节可以按 **ImageFolder -> 卷积 -> Dropout -> 学习率 -> Epoch** 的顺序读。第一个概念通常是入口，后面的概念要么是在补结构，要么是在解释训练时会遇到的问题。

### 1. 先讲 ImageFolder

先用最普通的话说，**ImageFolder** 就是：PyTorch 按文件夹名作为类别读取图像数据集的工具。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考目录结构与类别标签的对应关系。

如果按课件顺序串起来，可以这样看：**前面的概念 -> ImageFolder -> 卷积**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**ImageFolder：子文件夹名就是类别名。**

这里最容易错的是：文件夹结构不对会导致类别映射错误。

### 2. 先讲 卷积

先用最普通的话说，**卷积** 就是：用小窗口在图像局部滑动，对局部像素和卷积核权重相乘求和，提取边缘、纹理等局部特征。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考输出尺寸、卷积核/步长/填充的作用，以及 CNN 实际常用互相关。

如果按课件顺序串起来，可以这样看：**ImageFolder -> 卷积 -> Dropout**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**输出尺寸：(输入尺寸 + 2P - K) / S + 1。**

这里最容易错的是：不要把 CNN 说成全连接；卷积核心是局部连接和参数共享。

### 3. 先讲 Dropout

先用最普通的话说，**Dropout** 就是：训练时随机丢弃一部分神经元，迫使网络不要过度依赖某些特征。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考训练阶段启用、推理阶段关闭，以及它缓解过拟合。

如果按课件顺序串起来，可以这样看：**卷积 -> Dropout -> 学习率**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**Dropout：训练随机失活，推理正常使用。**

这里最容易错的是：Dropout 不是提高模型容量，而是正则化。

### 4. 先讲 学习率

先用最普通的话说，**学习率** 就是：控制每次参数沿梯度方向更新的步子大小。学习率太大容易震荡甚至发散，太小则收敛很慢。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考学习率过大/过小的训练现象，以及学习率调度的目的。

如果按课件顺序串起来，可以这样看：**Dropout -> 学习率 -> Epoch**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**学习率决定更新步长。**

这里最容易错的是：学习率不是越大越好；也不是模型学到的参数。

### 5. 先讲 Epoch

先用最普通的话说，**Epoch** 就是：训练集被模型完整看过一遍，叫一个 epoch。一个 epoch 内通常包含很多个 batch 更新。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考 Epoch、Batch、Iteration 的区别，或判断训练轮数增加对欠拟合/过拟合的影响。

如果按课件顺序串起来，可以这样看：**学习率 -> Epoch -> Adam**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**1 个 Epoch = 全部训练样本被用过一遍。**

这里最容易错的是：Epoch 不是一次参数更新；一次更新通常对应一个 batch。

### 6. 先讲 Adam

先用最普通的话说，**Adam** 就是：结合动量和自适应学习率思想，为不同参数调整更新幅度。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常和 SGD、Momentum、RMSProp 对比优化器特点。

如果按课件顺序串起来，可以这样看：**Epoch -> Adam -> 标准化**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**Adam = 一阶动量 + 二阶矩估计。**

这里最容易错的是：Adam 方便但不等于一定泛化最好，仍需调学习率等超参数。

### 7. 先讲 标准化

先用最普通的话说，**标准化** 就是：把数据按均值和方差调整到更稳定的尺度，帮助模型训练。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考归一化和标准化的区别、为什么图像输入要预处理。

如果按课件顺序串起来，可以这样看：**Adam -> 标准化 -> 数据增强**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**标准化常写作 (x-mean)/std。**

这里最容易错的是：不要把标准化简单等同于除以 255；标准化通常涉及均值和标准差。

### 8. 先讲 数据增强

先用最普通的话说，**数据增强** 就是：对训练数据做随机变换，增加样本多样性，缓解过拟合。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考图像翻转、裁剪、颜色扰动等增强方法。

如果按课件顺序串起来，可以这样看：**标准化 -> 数据增强 -> 池化**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**数据增强让模型见到更多合理变化。**

这里最容易错的是：数据增强通常只用于训练集，不应破坏标签含义。

### 9. 先讲 池化

先用最普通的话说，**池化** 就是：对局部区域做最大值或平均值汇总，降低空间尺寸并增强一定平移不变性。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考池化作用、是否有可学习参数、与卷积的区别。

如果按课件顺序串起来，可以这样看：**数据增强 -> 池化 -> 优化器**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**池化：降采样、压缩空间尺寸、保留显著信息。**

如果按课件顺序串起来，可以这样看：**标准化 -> Epoch -> 学习率**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**1 个 Epoch = 全部训练样本被用过一遍。**

这里最容易错的是：Epoch 不是一次参数更新；一次更新通常对应一个 batch。

### 9. 先讲 学习率

先用最普通的话说，**学习率** 就是：控制每次参数沿梯度方向更新的步子大小。学习率太大容易震荡甚至发散，太小则收敛很慢。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考学习率过大/过小的训练现象，以及学习率调度的目的。

如果按课件顺序串起来，可以这样看：**Epoch -> 学习率 -> 卷积核**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**学习率决定更新步长。**

这里最容易错的是：学习率不是越大越好；也不是模型学到的参数。

### 10. 先讲 卷积核

先用最普通的话说，**卷积核** 就是：卷积层中可学习的小矩阵/滤波器，用来扫描局部区域并提取特征。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考卷积核大小、通道数、参数共享和输出尺寸计算。

如果按课件顺序串起来，可以这样看：**学习率 -> 卷积核 -> 后面的概念**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**卷积核大小 K、步长 S、填充 P 共同决定输出尺寸。**

这里最容易错的是：卷积核参数会训练更新，不是手工固定模板。

### 这一节最后怎么记

- **迁移学习**：迁移学习利用已有特征减少训练成本。
- **AlexNet**：AlexNet 推动深度 CNN 在图像识别上突破。
- **ResNet**：ResNet 核心：y = F(x) + x。
- **VGG**：VGG：多层小卷积核堆叠。
- **卷积**：输出尺寸：(输入尺寸 + 2P - K) / S + 1。
- **Inception**：Inception = 多分支多尺度特征提取。

1. **选择题：关于 迁移学习，下列说法错误的是：**
   A. 把预训练模型学到的通用特征迁移到新任务上。
   B. 迁移学习利用已有特征减少训练成本。
   C. 常考冻结特征层、微调分类头或全模型微调。
   D. 迁移学习在 CNN 中通常用于增加全连接参数量，而不是保留图像结构。

   **答案：D。** A、B、C 都能和课件里的 迁移学习 对上；D 是把概念说反或放错位置。

2. **资料题：** 材料中出现 AlexNet，请判断它在本节属于数据、模型结构、训练优化还是输出目标，并说明理由。

   **参考答案：** 较早取得突破的深层 CNN，引入 ReLU、Dropout、数据增强等训练技巧。 答题时还要结合课件语境：常考它相比早期网络的改进。

3. **简答题：为什么考试里不能只背 ResNet 的定义？**

   **参考答案：** 因为 ResNet 在课件中有明确的位置和作用：用残差/跳跃连接让网络学习 F(x)+x，缓解深层网络退化和梯度传播困难。 答题时还要补出它通常怎么考：常考残差连接为什么能训练更深网络。 最后要避开这个误区：残差连接不是单纯增加层数，而是改变信息和梯度路径。

4. **辨析题：请区分 迁移学习 和 VGG。**

   **参考答案：** 迁移学习：把预训练模型学到的通用特征迁移到新任务上。；VGG：大量使用 3x3 小卷积核堆叠构建深层网络。。答题时先判断它们分别处在数据、结构、训练还是输出环节。

## 第 5 部分：第六章 CNN高级主题与应用 / 第3节：迁移学习

### 这一节先不要急着背

这一节可以按 **学习率 -> 卷积 -> 卷积核 -> 标准化 -> LeNet** 的顺序读。第一个概念通常是入口，后面的概念要么是在补结构，要么是在解释训练时会遇到的问题。

### 1. 先讲 学习率

先用最普通的话说，**学习率** 就是：控制每次参数沿梯度方向更新的步子大小。学习率太大容易震荡甚至发散，太小则收敛很慢。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考学习率过大/过小的训练现象，以及学习率调度的目的。

如果按课件顺序串起来，可以这样看：**前面的概念 -> 学习率 -> 卷积**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**学习率决定更新步长。**

这里最容易错的是：学习率不是越大越好；也不是模型学到的参数。

### 2. 先讲 卷积

先用最普通的话说，**卷积** 就是：用小窗口在图像局部滑动，对局部像素和卷积核权重相乘求和，提取边缘、纹理等局部特征。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考输出尺寸、卷积核/步长/填充的作用，以及 CNN 实际常用互相关。

如果按课件顺序串起来，可以这样看：**学习率 -> 卷积 -> 卷积核**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**输出尺寸：(输入尺寸 + 2P - K) / S + 1。**

这里最容易错的是：不要把 CNN 说成全连接；卷积核心是局部连接和参数共享。

### 3. 先讲 卷积核

先用最普通的话说，**卷积核** 就是：卷积层中可学习的小矩阵/滤波器，用来扫描局部区域并提取特征。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考卷积核大小、通道数、参数共享和输出尺寸计算。

如果按课件顺序串起来，可以这样看：**卷积 -> 卷积核 -> 标准化**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**卷积核大小 K、步长 S、填充 P 共同决定输出尺寸。**

这里最容易错的是：卷积核参数会训练更新，不是手工固定模板。

### 4. 先讲 标准化

先用最普通的话说，**标准化** 就是：把数据按均值和方差调整到更稳定的尺度，帮助模型训练。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考归一化和标准化的区别、为什么图像输入要预处理。

如果按课件顺序串起来，可以这样看：**卷积核 -> 标准化 -> LeNet**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**标准化常写作 (x-mean)/std。**

这里最容易错的是：不要把标准化简单等同于除以 255；标准化通常涉及均值和标准差。

### 5. 先讲 LeNet

先用最普通的话说，**LeNet** 就是：早期 CNN 结构，包含卷积、池化和全连接层，用于手写数字识别。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考 CNN 基本结构的历史代表。

如果按课件顺序串起来，可以这样看：**标准化 -> LeNet -> ImageFolder**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**LeNet 展示了卷积 + 池化 + 分类的基本流程。**

这里最容易错的是：不要把 LeNet 写成现代超深残差网络。

### 6. 先讲 ImageFolder

先用最普通的话说，**ImageFolder** 就是：PyTorch 按文件夹名作为类别读取图像数据集的工具。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考目录结构与类别标签的对应关系。

如果按课件顺序串起来，可以这样看：**LeNet -> ImageFolder -> 数据增强**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**ImageFolder：子文件夹名就是类别名。**

这里最容易错的是：文件夹结构不对会导致类别映射错误。

### 7. 先讲 数据增强

先用最普通的话说，**数据增强** 就是：对训练数据做随机变换，增加样本多样性，缓解过拟合。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考图像翻转、裁剪、颜色扰动等增强方法。

如果按课件顺序串起来，可以这样看：**ImageFolder -> 数据增强 -> 优化器**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**数据增强让模型见到更多合理变化。**

这里最容易错的是：数据增强通常只用于训练集，不应破坏标签含义。

### 8. 先讲 优化器

先用最普通的话说，**优化器** 就是：根据梯度和自身规则更新模型参数。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考 SGD、Momentum、RMSProp、Adam 的区别。

如果按课件顺序串起来，可以这样看：**数据增强 -> 优化器 -> Adam**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**优化器负责执行参数更新。**

这里最容易错的是：优化器不是损失函数；损失给目标，优化器改参数。

### 9. 先讲 Adam

先用最普通的话说，**Adam** 就是：结合动量和自适应学习率思想，为不同参数调整更新幅度。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常和 SGD、Momentum、RMSProp 对比优化器特点。

如果按课件顺序串起来，可以这样看：**优化器 -> Adam -> VGG**。

这里最容易错的是：Adam 方便但不等于一定泛化最好，仍需调学习率等超参数。

这里最容易错的是：不要把 VGG 的特点写成复杂多分支结构。
