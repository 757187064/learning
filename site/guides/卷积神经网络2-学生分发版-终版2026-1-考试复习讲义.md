## 先说整份课件到底在解决什么问题

这一份课件要解决的是：**图像不能简单当成一串数字直接丢给全连接网络。**

图像里有上下左右的位置关系，有局部纹理，也有边缘、角点、形状这些逐层组合出来的特征。CNN 的整个设计，就是为了让模型一层一层从局部看到整体。

所以读这份课件时，不要先背很多名词。先记住一条线：**图像有空间结构 -> 卷积保留局部结构 -> 池化压缩信息 -> 更深层网络组合高级特征。**

## 开始按课件一点一点讲

## 第 1 部分：第五章 神经网络训练技巧深度解析

### 这一节先不要急着背

这一节可以按 **学习率 -> 梯度消失 -> 梯度爆炸 -> 优化器 -> 超参数** 的顺序读。第一个概念通常是入口，后面的概念要么是在补结构，要么是在解释训练时会遇到的问题。

### 1. 先讲 学习率

先用最普通的话说，**学习率** 就是：控制每次参数沿梯度方向更新的步子大小。学习率太大容易震荡甚至发散，太小则收敛很慢。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考学习率过大/过小的训练现象，以及学习率调度的目的。

如果按课件顺序串起来，可以这样看：**前面的概念 -> 学习率 -> 梯度消失**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**学习率决定更新步长。**

这里最容易错的是：学习率不是越大越好；也不是模型学到的参数。

### 2. 先讲 梯度消失

先用最普通的话说，**梯度消失** 就是：反向传播经过很多层或很多时间步时，梯度可能不断变小，导致前面层或早期时间步很难学到东西。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考深层网络/RNN 为什么训练困难，以及 LSTM、GRU、残差连接如何缓解。

如果按课件顺序串起来，可以这样看：**学习率 -> 梯度消失 -> 梯度爆炸**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**多个小于 1 的因子连乘，会让梯度趋近 0。**

这里最容易错的是：梯度消失不是过拟合；它是参数难以有效更新的问题。

### 3. 先讲 梯度爆炸

先用最普通的话说，**梯度爆炸** 就是：梯度在反向传播中变得过大，使参数更新剧烈，训练损失可能震荡或变成 NaN。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考梯度裁剪为什么能缓解 RNN 训练不稳定。

如果按课件顺序串起来，可以这样看：**梯度消失 -> 梯度爆炸 -> 优化器**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**梯度裁剪限制梯度范数，防止更新步子过大。**

这里最容易错的是：Dropout 主要缓解过拟合，不是解决梯度爆炸的标准答案。

### 4. 先讲 优化器

先用最普通的话说，**优化器** 就是：根据梯度和自身规则更新模型参数。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考 SGD、Momentum、RMSProp、Adam 的区别。

如果按课件顺序串起来，可以这样看：**梯度爆炸 -> 优化器 -> 超参数**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**优化器负责执行参数更新。**

这里最容易错的是：优化器不是损失函数；损失给目标，优化器改参数。

### 5. 先讲 超参数

先用最普通的话说，**超参数** 就是：训练前人为设定的配置，如学习率、batch size、层数、dropout 比例。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考它和模型参数的区别。

如果按课件顺序串起来，可以这样看：**优化器 -> 超参数 -> 损失函数**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**超参数先设定，模型参数训练中学习。**

这里最容易错的是：超参数不是通过反向传播直接学出来的参数。

### 6. 先讲 损失函数

先用最普通的话说，**损失函数** 就是：把模型预测和真实标签之间的差距变成一个可优化的数值，反向传播就是从损失开始计算梯度。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考输出层与损失函数的匹配，例如多分类常配 CrossEntropyLoss，二分类可配 BCEWithLogitsLoss。

如果按课件顺序串起来，可以这样看：**超参数 -> 损失函数 -> Batch**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**损失函数告诉模型“错在哪里”，优化器负责“怎么改参数”。**

这里最容易错的是：不要把准确率当作训练损失；也不要把 BCE 和 CE 的适用场景混用。

### 7. 先讲 Batch

先用最普通的话说，**Batch** 就是：一次送入模型并一起计算损失的一组样本。它决定每次参数更新看到多少样本，也影响显存占用和训练稳定性。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考 batch size、mini-batch、epoch、iteration 的区别，也会结合张量形状中的 N 维度判断。

如果按课件顺序串起来，可以这样看：**损失函数 -> Batch -> Sigmoid**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**Batch 是一批样本；Epoch 是全训练集完整训练一遍。**

这里最容易错的是：Batch 不是序列长度；在 RNN 中常见形状里 N 是样本数，L 才是时间步长度。

### 8. 先讲 Sigmoid

先用最普通的话说，**Sigmoid** 就是：把任意实数压到 0 到 1 之间，可解释为概率或门控强度。GRU/LSTM 的门通常用它决定保留多少信息。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考输出范围、二分类概率、以及门控结构中为什么适合控制开关。

如果按课件顺序串起来，可以这样看：**Batch -> Sigmoid -> 激活函数**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**Sigmoid 输出在 0 到 1；越接近 1 越保留，越接近 0 越抑制。**

这里最容易错的是：Sigmoid 不只属于分类输出，在 RNN 门控里也很重要。

### 9. 先讲 激活函数

先用最普通的话说，**激活函数** 就是：给线性变换加入非线性，使网络能拟合非线性关系。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考没有激活函数时多层线性网络仍等价于线性模型。

如果按课件顺序串起来，可以这样看：**Sigmoid -> 激活函数 -> 卷积**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**仿射变换 + 激活函数 = 神经网络层的基本模式。**

这里最容易错的是：不要把激活函数说成只改变维度，它主要提供非线性。

### 10. 先讲 卷积

先用最普通的话说，**卷积** 就是：用小窗口在图像局部滑动，对局部像素和卷积核权重相乘求和，提取边缘、纹理等局部特征。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考输出尺寸、卷积核/步长/填充的作用，以及 CNN 实际常用互相关。

如果按课件顺序串起来，可以这样看：**激活函数 -> 卷积 -> 后面的概念**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**输出尺寸：(输入尺寸 + 2P - K) / S + 1。**

这里最容易错的是：不要把 CNN 说成全连接；卷积核心是局部连接和参数共享。

### 这一节最后怎么记

- **学习率**：学习率决定更新步长。
- **梯度消失**：多个小于 1 的因子连乘，会让梯度趋近 0。
- **梯度爆炸**：梯度裁剪限制梯度范数，防止更新步子过大。
- **优化器**：优化器负责执行参数更新。
- **超参数**：超参数先设定，模型参数训练中学习。
- **损失函数**：损失函数告诉模型“错在哪里”，优化器负责“怎么改参数”。

## 第 2 部分：第五章 神经网络训练技巧深度解析 / 第1节 梯度消失、梯度爆炸及其解决方案

### 1. 先讲 归一化

先用最普通的话说，**归一化** 就是：把数值缩放到较统一范围，例如图像像素从 0-255 缩放到 0-1。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考图像预处理为什么要缩放像素值。

如果按课件顺序串起来，可以这样看：**前面的概念 -> 归一化 -> 激活函数**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**图像常先把像素值缩放到 0-1。**

这里最容易错的是：归一化不等于 BatchNorm，前者多是输入预处理。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考 batch size、mini-batch、epoch、iteration 的区别，也会结合张量形状中的 N 维度判断。

### 7. 先讲 梯度裁剪

先用最普通的话说，**梯度裁剪** 就是：当梯度范数超过阈值时按比例缩小，常用于稳定 RNN 等容易梯度爆炸的训练。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考它处理的是梯度爆炸，而不是梯度消失。

也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**Gradient Clipping：限制梯度大小，稳定训练。**

这里最容易错的是：裁剪不是把梯度直接清零，而是限制其大小。

### 8. 先讲 卷积

先用最普通的话说，**卷积** 就是：用小窗口在图像局部滑动，对局部像素和卷积核权重相乘求和，提取边缘、纹理等局部特征。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考输出尺寸、卷积核/步长/填充的作用，以及 CNN 实际常用互相关。

如果按课件顺序串起来，可以这样看：**梯度裁剪 -> 卷积 -> 反向传播**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**输出尺寸：(输入尺寸 + 2P - K) / S + 1。**

这里最容易错的是：不要把 CNN 说成全连接；卷积核心是局部连接和参数共享。

### 9. 先讲 反向传播

先用最普通的话说，**反向传播** 就是：从损失函数出发，按链式法则把梯度传回各层参数。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考它和前向传播、损失函数、优化器的顺序关系。

如果按课件顺序串起来，可以这样看：**卷积 -> 反向传播 -> 标准化**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**前向算预测，损失算错误，反向算梯度。**

这里最容易错的是：反向传播只负责算梯度，真正改参数的是优化器。

### 10. 先讲 标准化

先用最普通的话说，**标准化** 就是：把数据按均值和方差调整到更稳定的尺度，帮助模型训练。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考归一化和标准化的区别、为什么图像输入要预处理。

如果按课件顺序串起来，可以这样看：**反向传播 -> 标准化 -> 后面的概念**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**标准化常写作 (x-mean)/std。**

这里最容易错的是：不要把标准化简单等同于除以 255；标准化通常涉及均值和标准差。

### 这一节最后怎么记

- **归一化**：图像常先把像素值缩放到 0-1。
- **激活函数**：仿射变换 + 激活函数 = 神经网络层的基本模式。
- **学习率**：学习率决定更新步长。

## 第 3 部分：第五章 神经网络训练技巧深度解析 / 第2节 优化器改进与学习率调整

### 这一节先不要急着背

这一节可以按 **学习率 -> Adam -> 优化器 -> RMSProp -> Momentum** 的顺序读。第一个概念通常是入口，后面的概念要么是在补结构，要么是在解释训练时会遇到的问题。

### 1. 先讲 学习率

先用最普通的话说，**学习率** 就是：控制每次参数沿梯度方向更新的步子大小。学习率太大容易震荡甚至发散，太小则收敛很慢。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考学习率过大/过小的训练现象，以及学习率调度的目的。

如果按课件顺序串起来，可以这样看：**前面的概念 -> 学习率 -> Adam**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**学习率决定更新步长。**

这里最容易错的是：学习率不是越大越好；也不是模型学到的参数。

### 2. 先讲 Adam

先用最普通的话说，**Adam** 就是：结合动量和自适应学习率思想，为不同参数调整更新幅度。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常和 SGD、Momentum、RMSProp 对比优化器特点。

如果按课件顺序串起来，可以这样看：**学习率 -> Adam -> 优化器**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**Adam = 一阶动量 + 二阶矩估计。**

这里最容易错的是：Adam 方便但不等于一定泛化最好，仍需调学习率等超参数。

### 3. 先讲 优化器

先用最普通的话说，**优化器** 就是：根据梯度和自身规则更新模型参数。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考 SGD、Momentum、RMSProp、Adam 的区别。

如果按课件顺序串起来，可以这样看：**Adam -> 优化器 -> RMSProp**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**优化器负责执行参数更新。**

这里最容易错的是：优化器不是损失函数；损失给目标，优化器改参数。

### 4. 先讲 RMSProp

先用最普通的话说，**RMSProp** 就是：用梯度平方的指数滑动平均调整学习率，缓解 Adagrad 学习率过快衰减。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考它和 Adagrad 的区别。

如果按课件顺序串起来，可以这样看：**优化器 -> RMSProp -> Momentum**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**RMSProp 使用指数滑动平均保存近期梯度尺度。**

这里最容易错的是：不要写成简单固定学习率下降。

### 5. 先讲 Momentum

先用最普通的话说，**Momentum** 就是：在梯度下降中加入历史更新方向，让更新更平滑、减少震荡。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考它为什么能加速或稳定训练。

如果按课件顺序串起来，可以这样看：**RMSProp -> Momentum -> 梯度下降**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**Momentum 像给梯度下降加惯性。**

这里最容易错的是：Momentum 不是学习率本身，而是利用历史梯度趋势。

### 6. 先讲 梯度下降

先用最普通的话说，**梯度下降** 就是：沿着损失函数下降最快的方向调整参数，让模型预测逐步变好。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考参数更新方向、学习率作用、训练循环位置。

如果按课件顺序串起来，可以这样看：**Momentum -> 梯度下降 -> ResNet**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**参数更新方向通常与梯度相反。**

这里最容易错的是：梯度下降不是直接调准确率，而是通过损失函数和梯度改参数。

### 7. 先讲 ResNet

先用最普通的话说，**ResNet** 就是：用残差/跳跃连接让网络学习 F(x)+x，缓解深层网络退化和梯度传播困难。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考残差连接为什么能训练更深网络。

如果按课件顺序串起来，可以这样看：**梯度下降 -> ResNet -> Epoch**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**ResNet 核心：y = F(x) + x。**

这里最容易错的是：残差连接不是单纯增加层数，而是改变信息和梯度路径。

### 8. 先讲 Epoch

先用最普通的话说，**Epoch** 就是：训练集被模型完整看过一遍，叫一个 epoch。一个 epoch 内通常包含很多个 batch 更新。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考 Epoch、Batch、Iteration 的区别，或判断训练轮数增加对欠拟合/过拟合的影响。

如果按课件顺序串起来，可以这样看：**ResNet -> Epoch -> 梯度消失**。

考试写到这里，最稳的一句话是：**1 个 Epoch = 全部训练样本被用过一遍。**

这里最容易错的是：Epoch 不是一次参数更新；一次更新通常对应一个 batch。

### 9. 先讲 梯度消失

先用最普通的话说，**梯度消失** 就是：反向传播经过很多层或很多时间步时，梯度可能不断变小，导致前面层或早期时间步很难学到东西。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考深层网络/RNN 为什么训练困难，以及 LSTM、GRU、残差连接如何缓解。

如果按课件顺序串起来，可以这样看：**Epoch -> 梯度消失 -> 步长**。

考试写到这里，最稳的一句话是：**多个小于 1 的因子连乘，会让梯度趋近 0。**

这里最容易错的是：梯度消失不是过拟合；它是参数难以有效更新的问题。

### 10. 先讲 步长

先用最普通的话说，**步长** 就是：卷积核或池化窗口每次移动的间隔。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考步长变大时输出尺寸如何变化。

考试写到这里，最稳的一句话是：**Stride 控制滑动间隔。**

这里最容易错的是：步长越大，输出空间尺寸通常越小。

### 这一节最后怎么记

- **学习率**：学习率决定更新步长。
- **Adam**：Adam = 一阶动量 + 二阶矩估计。
- **优化器**：优化器负责执行参数更新。

## 第 4 部分：第五章 神经网络训练技巧深度解析 / 第3节 处理过拟合的综合策略

先用最普通的话说，**卷积** 就是：用小窗口在图像局部滑动，对局部像素和卷积核权重相乘求和，提取边缘、纹理等局部特征。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考输出尺寸、卷积核/步长/填充的作用，以及 CNN 实际常用互相关。

如果按课件顺序串起来，可以这样看：**数据增强 -> 卷积 -> 权重衰减**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**输出尺寸：(输入尺寸 + 2P - K) / S + 1。**

### 4. 先讲 权重衰减

先用最普通的话说，**权重衰减** 就是：通过惩罚过大的权重来正则化模型，常用于缓解过拟合。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考它和 L2 正则化、过拟合控制的关系。

### 5. 先讲 损失函数

先用最普通的话说，**损失函数** 就是：把模型预测和真实标签之间的差距变成一个可优化的数值，反向传播就是从损失开始计算梯度。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考输出层与损失函数的匹配，例如多分类常配 CrossEntropyLoss，二分类可配 BCEWithLogitsLoss。

如果按课件顺序串起来，可以这样看：**权重衰减 -> 损失函数 -> Epoch**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**损失函数告诉模型“错在哪里”，优化器负责“怎么改参数”。**

这里最容易错的是：不要把准确率当作训练损失；也不要把 BCE 和 CE 的适用场景混用。

### 6. 先讲 Epoch

先用最普通的话说，**Epoch** 就是：训练集被模型完整看过一遍，叫一个 epoch。一个 epoch 内通常包含很多个 batch 更新。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考 Epoch、Batch、Iteration 的区别，或判断训练轮数增加对欠拟合/过拟合的影响。

如果按课件顺序串起来，可以这样看：**损失函数 -> Epoch -> 交叉熵**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**1 个 Epoch = 全部训练样本被用过一遍。**

这里最容易错的是：Epoch 不是一次参数更新；一次更新通常对应一个 batch。

### 7. 先讲 交叉熵

先用最普通的话说，**交叉熵** 就是：衡量预测概率分布与真实类别之间差距的分类损失。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考多分类用 CrossEntropyLoss，二分类/多标签用 BCE 类损失。

如果按课件顺序串起来，可以这样看：**Epoch -> 交叉熵 -> 后面的概念**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**交叉熵越小，预测分布越接近真实标签。**

这里最容易错的是：不要把交叉熵和准确率混成同一个东西。

### 这一节最后怎么记

- **Dropout**：Dropout：训练随机失活，推理正常使用。
- **数据增强**：数据增强让模型见到更多合理变化。
- **卷积**：输出尺寸：(输入尺寸 + 2P - K) / S + 1。
- **权重衰减**：权重衰减限制参数过大。
- **损失函数**：损失函数告诉模型“错在哪里”，优化器负责“怎么改参数”。
- **Epoch**：1 个 Epoch = 全部训练样本被用过一遍。

### 本节检查题

1. **选择题：关于 Dropout，下列说法错误的是：**
   A. 训练时随机丢弃一部分神经元，迫使网络不要过度依赖某些特征。
   B. Dropout：训练随机失活，推理正常使用。
   C. 常考训练阶段启用、推理阶段关闭，以及它缓解过拟合。
   D. Dropout 推理阶段仍要随机丢弃神经元。

   **答案：D。** A、B、C 都能和课件里的 Dropout 对上；D 是把概念说反或放错位置。

2. **填空题：** 数据增强 的复习重点不是只写名称，而是写清它的作用：____。

   **参考答案：** 对训练数据做随机变换，增加样本多样性，缓解过拟合。

3. **简答题：为什么考试里不能只背 卷积 的定义？**

   **参考答案：** 因为 卷积 在课件中有明确的位置和作用：用小窗口在图像局部滑动，对局部像素和卷积核权重相乘求和，提取边缘、纹理等局部特征。 答题时还要补出它通常怎么考：常考输出尺寸、卷积核/步长/填充的作用，以及 CNN 实际常用互相关。 最后要避开这个误区：不要把 CNN 说成全连接；卷积核心是局部连接和参数共享。

4. **辨析题：请区分 Dropout 和 权重衰减。**

   **参考答案：** Dropout：训练时随机丢弃一部分神经元，迫使网络不要过度依赖某些特征。；权重衰减：通过惩罚过大的权重来正则化模型，常用于缓解过拟合。。答题时先判断它们分别处在数据、结构、训练还是输出环节。

## 第 5 部分：第五章 神经网络训练技巧深度解析 / 第4节 超参数选取实践指南

### 这一节先不要急着背

这一节可以按 **Batch -> 优化器 -> Adam -> Epoch -> 学习率** 的顺序读。第一个概念通常是入口，后面的概念要么是在补结构，要么是在解释训练时会遇到的问题。

### 1. 先讲 Batch

先用最普通的话说，**Batch** 就是：一次送入模型并一起计算损失的一组样本。它决定每次参数更新看到多少样本，也影响显存占用和训练稳定性。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考 batch size、mini-batch、epoch、iteration 的区别，也会结合张量形状中的 N 维度判断。

如果按课件顺序串起来，可以这样看：**前面的概念 -> Batch -> 优化器**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**Batch 是一批样本；Epoch 是全训练集完整训练一遍。**

这里最容易错的是：Batch 不是序列长度；在 RNN 中常见形状里 N 是样本数，L 才是时间步长度。

### 2. 先讲 优化器

先用最普通的话说，**优化器** 就是：根据梯度和自身规则更新模型参数。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考 SGD、Momentum、RMSProp、Adam 的区别。

如果按课件顺序串起来，可以这样看：**Batch -> 优化器 -> Adam**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**优化器负责执行参数更新。**

这里最容易错的是：优化器不是损失函数；损失给目标，优化器改参数。

### 3. 先讲 Adam

先用最普通的话说，**Adam** 就是：结合动量和自适应学习率思想，为不同参数调整更新幅度。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常和 SGD、Momentum、RMSProp 对比优化器特点。

如果按课件顺序串起来，可以这样看：**优化器 -> Adam -> Epoch**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**Adam = 一阶动量 + 二阶矩估计。**

这里最容易错的是：Adam 方便但不等于一定泛化最好，仍需调学习率等超参数。

### 4. 先讲 Epoch

先用最普通的话说，**Epoch** 就是：训练集被模型完整看过一遍，叫一个 epoch。一个 epoch 内通常包含很多个 batch 更新。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考 Epoch、Batch、Iteration 的区别，或判断训练轮数增加对欠拟合/过拟合的影响。

如果按课件顺序串起来，可以这样看：**Adam -> Epoch -> 学习率**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**1 个 Epoch = 全部训练样本被用过一遍。**

这里最容易错的是：Epoch 不是一次参数更新；一次更新通常对应一个 batch。

### 5. 先讲 学习率

先用最普通的话说，**学习率** 就是：控制每次参数沿梯度方向更新的步子大小。学习率太大容易震荡甚至发散，太小则收敛很慢。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考学习率过大/过小的训练现象，以及学习率调度的目的。

如果按课件顺序串起来，可以这样看：**Epoch -> 学习率 -> Dropout**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**学习率决定更新步长。**

这里最容易错的是：学习率不是越大越好；也不是模型学到的参数。

### 6. 先讲 Dropout

先用最普通的话说，**Dropout** 就是：训练时随机丢弃一部分神经元，迫使网络不要过度依赖某些特征。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考训练阶段启用、推理阶段关闭，以及它缓解过拟合。

如果按课件顺序串起来，可以这样看：**学习率 -> Dropout -> 权重衰减**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**Dropout：训练随机失活，推理正常使用。**

这里最容易错的是：Dropout 不是提高模型容量，而是正则化。

### 7. 先讲 权重衰减

先用最普通的话说，**权重衰减** 就是：通过惩罚过大的权重来正则化模型，常用于缓解过拟合。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考它和 L2 正则化、过拟合控制的关系。

如果按课件顺序串起来，可以这样看：**Dropout -> 权重衰减 -> Momentum**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**权重衰减限制参数过大。**

这里最容易错的是：不要把权重衰减当成学习率衰减。

### 8. 先讲 Momentum

先用最普通的话说，**Momentum** 就是：在梯度下降中加入历史更新方向，让更新更平滑、减少震荡。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考它为什么能加速或稳定训练。

如果按课件顺序串起来，可以这样看：**权重衰减 -> Momentum -> ResNet**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**Momentum 像给梯度下降加惯性。**

这里最容易错的是：Momentum 不是学习率本身，而是利用历史梯度趋势。

### 9. 先讲 ResNet

先用最普通的话说，**ResNet** 就是：用残差/跳跃连接让网络学习 F(x)+x，缓解深层网络退化和梯度传播困难。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考残差连接为什么能训练更深网络。

如果按课件顺序串起来，可以这样看：**Momentum -> ResNet -> 超参数**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**ResNet 核心：y = F(x) + x。**

这里最容易错的是：残差连接不是单纯增加层数，而是改变信息和梯度路径。

### 10. 先讲 超参数

先用最普通的话说，**超参数** 就是：训练前人为设定的配置，如学习率、batch size、层数、dropout 比例。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考它和模型参数的区别。

如果按课件顺序串起来，可以这样看：**ResNet -> 超参数 -> 后面的概念**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**超参数先设定，模型参数训练中学习。**

这里最容易错的是：超参数不是通过反向传播直接学出来的参数。

### 这一节最后怎么记

- **Batch**：Batch 是一批样本；Epoch 是全训练集完整训练一遍。
- **优化器**：优化器负责执行参数更新。
- **Adam**：Adam = 一阶动量 + 二阶矩估计。
- **Epoch**：1 个 Epoch = 全部训练样本被用过一遍。
- **学习率**：学习率决定更新步长。
- **Dropout**：Dropout：训练随机失活，推理正常使用。

   A. 一次送入模型并一起计算损失的一组样本。它决定每次参数更新看到多少样本，也影响显存占用和训练稳定性。
   B. Batch 是一批样本；Epoch 是全训练集完整训练一遍。
