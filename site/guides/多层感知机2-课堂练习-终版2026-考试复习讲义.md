## 一、这份课件先解决什么问题

这一类课件是深度学习入门骨架：先理解线性变换和激活函数，再理解损失函数、反向传播、优化器和训练流程。

考试常围绕“为什么需要非线性”“分类输出层和损失函数怎么匹配”“训练循环每一步做什么”来考。

## 第 1 部分：多层感知机 - 课堂练习

### 1. 本节先看什么

这一节先把 **Softmax、Sigmoid、多层感知机** 放到同一条知识链里理解。不要先背细节，先问自己：它在输入、模型结构、训练流程、损失函数或评估里处在哪一步？

### 3. 像考试答案一样组织语言

- **Softmax**：把一组分数转成和为 1 的概率分布，常用于多分类或注意力权重。 考试写作时要补一句：常考多分类输出、注意力权重为什么能加权求和。 易错点是：Softmax 是对一组数整体归一化，不是逐个独立压缩。
- **Sigmoid**：把任意实数压到 0 到 1 之间，可解释为概率或门控强度。GRU/LSTM 的门通常用它决定保留多少信息。 考试写作时要补一句：常考输出范围、二分类概率、以及门控结构中为什么适合控制开关。 易错点是：Sigmoid 不只属于分类输出，在 RNN 门控里也很重要。
- **多层感知机**：多层感知机 - 课堂练习；本练习包含三个部分，分别对应课件中的核心知识点：；练习1：概率与Logit的相互转换（Sigmoid函数理解）；练习2：Softmax手动计算（多分类概率理解） 考试写作时要补一句：会结合前向传播、损失函数、梯度下降、激活函数或分类输出层一起考。 易错点是：不要把线性变换、非线性激活、损失函数和优化器的职责混在一起。

### 4. 本节自测

- 判断：Softmax只需要背定义，不需要知道它在模型或训练流程中的位置。（答案：错。复习时必须结合“作用 + 位置 + 易错点”。）
- 判断：Sigmoid只需要背定义，不需要知道它在模型或训练流程中的位置。（答案：错。复习时必须结合“作用 + 位置 + 易错点”。）
- 判断：多层感知机只需要背定义，不需要知道它在模型或训练流程中的位置。（答案：错。复习时必须结合“作用 + 位置 + 易错点”。）

### 5. 本节速记

- Softmax 输出非负且总和为 1。
- Sigmoid 输出在 0 到 1；越接近 1 越保留，越接近 0 越抑制。
- 多层感知机 - 课堂练习；本练习包含三个部分，分别对应课件中的核心知识点：；练习1：概率与Logit的相互转换（Sigmoid函数理解）；练习2：Softmax手动计算（多分类概率理解）
