## 先说整份课件到底在解决什么问题

这一份课件要解决的是：**当数据本身是一张图时，模型怎样同时利用节点特征和节点之间的关系。**

图学习最重要的不是某个模型名字，而是“对象之间有边，边决定信息怎么传”。GNN 的很多方法都可以看成邻居信息的聚合和更新。

读的时候先抓这条线：**节点/边 -> 邻接矩阵 -> 图任务类型 -> 随机游走或表示学习 -> GCN/GAT 等图神经网络。**

## 第 1 部分：什么是图？

### 这一节先不要急着背

这一节可以按 **节点 -> Edge** 的顺序读。第一个概念通常是入口，后面的概念要么是在补结构，要么是在解释训练时会遇到的问题。

### 1. 先讲 节点

先用最普通的话说，**节点** 就是：图中的对象或实体，可以带有节点特征。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考节点分类任务：预测每个节点的类别。

如果按课件顺序串起来，可以这样看：**前面的概念 -> 节点 -> Edge**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**节点表示对象，边表示对象之间的关系。**

这里最容易错的是：节点特征和边关系是两类信息，不要混在一起。

### 2. 先讲 Edge

先用最普通的话说，**Edge** 就是：图中的边，表示两个节点之间的关系，可以有方向和权重。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考 Edge 与邻接矩阵元素的对应关系。

如果按课件顺序串起来，可以这样看：**节点 -> Edge -> 后面的概念**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**Edge 表示关系，A_ij 常记录边或边权。**

这里最容易错的是：Edge 不是节点特征本身，而是节点之间的连接。

### 这一节最后怎么记

- **节点**：节点表示对象，边表示对象之间的关系。
- **Edge**：Edge 表示关系，A_ij 常记录边或边权。

### 本节检查题

1. **选择题：关于 节点，下列说法错误的是：**
   A. 图中的对象或实体，可以带有节点特征。

   C. 常考节点分类任务：预测每个节点的类别。
   D. 节点表示关系，边表示对象。

   **答案：D。** A、B、C 都能和课件里的 节点 对上；D 是把概念说反或放错位置。

2. **填空题：** Edge 的复习重点不是只写名称，而是写清它的作用：____。

   **参考答案：** 图中的边，表示两个节点之间的关系，可以有方向和权重。

### 5. 先讲 拉普拉斯矩阵

先用最普通的话说，**拉普拉斯矩阵** 就是：用度矩阵和邻接矩阵构造，反映图的连接结构。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考 L=D-A 以及它在谱图方法中的作用。

如果按课件顺序串起来，可以这样看：**度矩阵 -> 拉普拉斯矩阵 -> 后面的概念**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**图拉普拉斯：L = D - A。**

这里最容易错的是：不要把 L 和 A 混用。

### 这一节最后怎么记

- **图学习**：图学习 = 特征信息 + 结构信息。
- **节点**：节点表示对象，边表示对象之间的关系。
- **邻接矩阵**：A_ij 表示 i 到 j 是否有边或边权。
- **度矩阵**：D_ii = 节点 i 的度。
- **拉普拉斯矩阵**：图拉普拉斯：L = D - A。

### 本节检查题

1. **选择题：关于 图学习，下列说法错误的是：**
   A. 研究如何在图结构数据上学习表示和完成预测，核心是同时利用节点特征与关系结构。
   B. 图学习 = 特征信息 + 结构信息。
   C. 常考图数据适用场景、节点/边/图级任务。
   D. 图学习只看单个样本特征，不需要关系结构。

   **答案：D。** A、B、C 都能和课件里的 图学习 对上；D 是把概念说反或放错位置。

2. **填空题：** 节点 的复习重点不是只写名称，而是写清它的作用：____。

   **参考答案：** 图中的对象或实体，可以带有节点特征。

3. **简答题：为什么考试里不能只背 邻接矩阵 的定义？**

   **参考答案：** 因为 邻接矩阵 在课件中有明确的位置和作用：用矩阵记录节点之间是否相连或连接权重。 答题时还要补出它通常怎么考：常考根据图画矩阵，或根据矩阵判断邻居。 最后要避开这个误区：无向图邻接矩阵通常对称；有向图不一定对称。

4. **辨析题：请区分 图学习 和 度矩阵。**

   **参考答案：** 图学习：研究如何在图结构数据上学习表示和完成预测，核心是同时利用节点特征与关系结构。；度矩阵：对角矩阵，对角线记录每个节点的度。。答题时先判断它们分别处在数据、结构、训练还是输出环节。
