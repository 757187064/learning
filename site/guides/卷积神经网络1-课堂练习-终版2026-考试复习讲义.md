## 先说整份课件到底在解决什么问题

这一份课件要解决的是：**图像不能简单当成一串数字直接丢给全连接网络。**

图像里有上下左右的位置关系，有局部纹理，也有边缘、角点、形状这些逐层组合出来的特征。CNN 的整个设计，就是为了让模型一层一层从局部看到整体。

所以读这份课件时，不要先背很多名词。先记住一条线：**图像有空间结构 -> 卷积保留局部结构 -> 池化压缩信息 -> 更深层网络组合高级特征。**

## 开始按课件一点一点讲

## 第 1 部分：第四章 卷积神经网络 - 课堂练习

### 这一节先不要急着背

这一节可以按 **卷积 -> 感受野 -> 池化 -> 卷积核 -> 步长** 的顺序读。第一个概念通常是入口，后面的概念要么是在补结构，要么是在解释训练时会遇到的问题。

### 1. 先讲 卷积

先用最普通的话说，**卷积** 就是：用小窗口在图像局部滑动，对局部像素和卷积核权重相乘求和，提取边缘、纹理等局部特征。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考输出尺寸、卷积核/步长/填充的作用，以及 CNN 实际常用互相关。

如果按课件顺序串起来，可以这样看：**前面的概念 -> 卷积 -> 感受野**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**输出尺寸：(输入尺寸 + 2P - K) / S + 1。**

这里最容易错的是：不要把 CNN 说成全连接；卷积核心是局部连接和参数共享。

### 2. 先讲 感受野

先用最普通的话说，**感受野** 就是：某一层一个神经元能看到原始输入图像的区域大小。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考层数、卷积核大小、步长如何影响感受野。

如果按课件顺序串起来，可以这样看：**卷积 -> 感受野 -> 池化**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**层越深，感受野通常越大；多层小卷积能逐步扩大感受野。**

这里最容易错的是：步长变大通常会让前一层对应感受野扩大，不是缩小。

### 3. 先讲 池化

先用最普通的话说，**池化** 就是：对局部区域做最大值或平均值汇总，降低空间尺寸并增强一定平移不变性。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考池化作用、是否有可学习参数、与卷积的区别。

如果按课件顺序串起来，可以这样看：**感受野 -> 池化 -> 卷积核**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**池化：降采样、压缩空间尺寸、保留显著信息。**

这里最容易错的是：池化不是全连接，也不是用来增加参数量。

### 4. 先讲 卷积核

先用最普通的话说，**卷积核** 就是：卷积层中可学习的小矩阵/滤波器，用来扫描局部区域并提取特征。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考卷积核大小、通道数、参数共享和输出尺寸计算。

如果按课件顺序串起来，可以这样看：**池化 -> 卷积核 -> 步长**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**卷积核大小 K、步长 S、填充 P 共同决定输出尺寸。**

这里最容易错的是：卷积核参数会训练更新，不是手工固定模板。

### 5. 先讲 步长

先用最普通的话说，**步长** 就是：卷积核或池化窗口每次移动的间隔。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考步长变大时输出尺寸如何变化。

如果按课件顺序串起来，可以这样看：**卷积核 -> 步长 -> 激活函数**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**Stride 控制滑动间隔。**

这里最容易错的是：步长越大，输出空间尺寸通常越小。

### 6. 先讲 激活函数

先用最普通的话说，**激活函数** 就是：给线性变换加入非线性，使网络能拟合非线性关系。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考没有激活函数时多层线性网络仍等价于线性模型。

如果按课件顺序串起来，可以这样看：**步长 -> 激活函数 -> Valid**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**仿射变换 + 激活函数 = 神经网络层的基本模式。**

这里最容易错的是：不要把激活函数说成只改变维度，它主要提供非线性。

### 7. 先讲 Valid

先用最普通的话说，**Valid** 就是：不填充边界，只在卷积核完全落入输入时计算，输出尺寸会变小。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常和 Same、Full 对比考输出大小。

如果按课件顺序串起来，可以这样看：**激活函数 -> Valid -> 填充**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**Valid：无填充，输出通常最小。**

这里最容易错的是：Valid 不是大量填充，恰好是不填充。

### 8. 先讲 填充

先用最普通的话说，**填充** 就是：在输入边界补值，让卷积能处理边缘或保持输出尺寸。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考 Same 卷积为何需要 padding。

如果按课件顺序串起来，可以这样看：**Valid -> 填充 -> 后面的概念**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**Padding 用于控制输出尺寸和边界信息。**

这里最容易错的是：填充不是增加有效信息，而是控制边界和尺寸。

### 这一节最后怎么记

- **卷积**：输出尺寸：(输入尺寸 + 2P - K) / S + 1。
- **感受野**：层越深，感受野通常越大；多层小卷积能逐步扩大感受野。
- **池化**：池化：降采样、压缩空间尺寸、保留显著信息。
- **卷积核**：卷积核大小 K、步长 S、填充 P 共同决定输出尺寸。
- **步长**：Stride 控制滑动间隔。
- **激活函数**：仿射变换 + 激活函数 = 神经网络层的基本模式。

### 本节检查题

1. **选择题：关于 卷积，下列说法错误的是：**
   A. 用小窗口在图像局部滑动，对局部像素和卷积核权重相乘求和，提取边缘、纹理等局部特征。
   B. 输出尺寸：(输入尺寸 + 2P - K) / S + 1。
   C. 常考输出尺寸、卷积核/步长/填充的作用，以及 CNN 实际常用互相关。
   D. 卷积层会把所有像素完全展开后做全连接，因此主要靠增加参数量提升效果。

   **答案：D。** A、B、C 都能和课件里的 卷积 对上；D 是把概念说反或放错位置。

2. **填空题：** 感受野 的复习重点不是只写名称，而是写清它的作用：____。

   **参考答案：** 某一层一个神经元能看到原始输入图像的区域大小。

3. **简答题：为什么考试里不能只背 池化 的定义？**

   **参考答案：** 因为 池化 在课件中有明确的位置和作用：对局部区域做最大值或平均值汇总，降低空间尺寸并增强一定平移不变性。 答题时还要补出它通常怎么考：常考池化作用、是否有可学习参数、与卷积的区别。 最后要避开这个误区：池化不是全连接，也不是用来增加参数量。

4. **辨析题：请区分 卷积 和 卷积核。**

   **参考答案：** 卷积：用小窗口在图像局部滑动，对局部像素和卷积核权重相乘求和，提取边缘、纹理等局部特征。；卷积核：卷积层中可学习的小矩阵/滤波器，用来扫描局部区域并提取特征。。答题时先判断它们分别处在数据、结构、训练还是输出环节。
