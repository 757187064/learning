## 先说整份课件到底在解决什么问题

这一份课件要解决的是：**图像不能简单当成一串数字直接丢给全连接网络。**

图像里有上下左右的位置关系，有局部纹理，也有边缘、角点、形状这些逐层组合出来的特征。CNN 的整个设计，就是为了让模型一层一层从局部看到整体。

所以读这份课件时，不要先背很多名词。先记住一条线：**图像有空间结构 -> 卷积保留局部结构 -> 池化压缩信息 -> 更深层网络组合高级特征。**

## 开始按课件一点一点讲

## 第 1 部分：第四章 卷积神经网络基础与入门实践

### 这一节先不要急着背

这一节可以按 **卷积 -> 感受野 -> 池化 -> 卷积核 -> 损失函数** 的顺序读。第一个概念通常是入口，后面的概念要么是在补结构，要么是在解释训练时会遇到的问题。

### 1. 先讲 卷积

先用最普通的话说，**卷积** 就是：用小窗口在图像局部滑动，对局部像素和卷积核权重相乘求和，提取边缘、纹理等局部特征。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考输出尺寸、卷积核/步长/填充的作用，以及 CNN 实际常用互相关。

如果按课件顺序串起来，可以这样看：**前面的概念 -> 卷积 -> 感受野**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**输出尺寸：(输入尺寸 + 2P - K) / S + 1。**

这里最容易错的是：不要把 CNN 说成全连接；卷积核心是局部连接和参数共享。

### 2. 先讲 感受野

先用最普通的话说，**感受野** 就是：某一层一个神经元能看到原始输入图像的区域大小。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考层数、卷积核大小、步长如何影响感受野。

如果按课件顺序串起来，可以这样看：**卷积 -> 感受野 -> 池化**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**层越深，感受野通常越大；多层小卷积能逐步扩大感受野。**

这里最容易错的是：步长变大通常会让前一层对应感受野扩大，不是缩小。

### 3. 先讲 池化

先用最普通的话说，**池化** 就是：对局部区域做最大值或平均值汇总，降低空间尺寸并增强一定平移不变性。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考池化作用、是否有可学习参数、与卷积的区别。

如果按课件顺序串起来，可以这样看：**感受野 -> 池化 -> 卷积核**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**池化：降采样、压缩空间尺寸、保留显著信息。**

这里最容易错的是：池化不是全连接，也不是用来增加参数量。

### 4. 先讲 卷积核

先用最普通的话说，**卷积核** 就是：卷积层中可学习的小矩阵/滤波器，用来扫描局部区域并提取特征。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考卷积核大小、通道数、参数共享和输出尺寸计算。

如果按课件顺序串起来，可以这样看：**池化 -> 卷积核 -> 损失函数**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**卷积核大小 K、步长 S、填充 P 共同决定输出尺寸。**

这里最容易错的是：卷积核参数会训练更新，不是手工固定模板。

### 5. 先讲 损失函数

先用最普通的话说，**损失函数** 就是：把模型预测和真实标签之间的差距变成一个可优化的数值，反向传播就是从损失开始计算梯度。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考输出层与损失函数的匹配，例如多分类常配 CrossEntropyLoss，二分类可配 BCEWithLogitsLoss。

如果按课件顺序串起来，可以这样看：**卷积核 -> 损失函数 -> 互相关**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**损失函数告诉模型“错在哪里”，优化器负责“怎么改参数”。**

这里最容易错的是：不要把准确率当作训练损失；也不要把 BCE 和 CE 的适用场景混用。

### 6. 先讲 互相关

先用最普通的话说，**互相关** 就是：形式接近卷积，但不翻转卷积核；深度学习框架里的卷积层通常实际做互相关。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考 CNN 中是否需要翻转卷积核，或为什么工程上用互相关。

如果按课件顺序串起来，可以这样看：**损失函数 -> 互相关 -> Valid**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**CNN 训练会学习卷积核参数，因此互相关也能学到有效特征。**

这里最容易错的是：不要因为名字叫卷积层，就默认一定执行数学卷积的核翻转。

### 7. 先讲 Valid

先用最普通的话说，**Valid** 就是：不填充边界，只在卷积核完全落入输入时计算，输出尺寸会变小。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常和 Same、Full 对比考输出大小。

如果按课件顺序串起来，可以这样看：**互相关 -> Valid -> Same**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**Valid：无填充，输出通常最小。**

这里最容易错的是：Valid 不是大量填充，恰好是不填充。

### 8. 先讲 Same

先用最普通的话说，**Same** 就是：通过适当填充，让卷积输出空间尺寸尽量和输入保持一致。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考给定输入、卷积核、步长时需要多少 padding。

如果按课件顺序串起来，可以这样看：**Valid -> Same -> Full**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**步长为 1 时，Same 卷积常让 H、W 不变。**

这里最容易错的是：Same 的目标是保持尺寸，不是扩大特征图。

### 9. 先讲 Full

先用最普通的话说，**Full** 就是：在边界外进行更充分的填充，使卷积核可以覆盖到输入边缘外侧，输出会变大。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常和 Valid、Same 放在一起判断哪种输出最大。

如果按课件顺序串起来，可以这样看：**Same -> Full -> NCHW**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**Full：充分填充，输出通常最大。**

这里最容易错的是：Full 不是常规 CNN 默认选择，考试多用于概念区分。

### 10. 先讲 NCHW

先用最普通的话说，**NCHW** 就是：图像张量格式，依次表示 Batch、Channel、Height、Width，PyTorch 中很常见。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考 NCHW 与 NHWC 的维度顺序，以及卷积层输入通道位置。

如果按课件顺序串起来，可以这样看：**Full -> NCHW -> 后面的概念**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**NCHW = Batch, Channel, Height, Width。**

这里最容易错的是：不要把 Channel 和 Height/Width 顺序写反。

### 这一节最后怎么记

- **卷积**：输出尺寸：(输入尺寸 + 2P - K) / S + 1。
- **感受野**：层越深，感受野通常越大；多层小卷积能逐步扩大感受野。
- **池化**：池化：降采样、压缩空间尺寸、保留显著信息。
- **卷积核**：卷积核大小 K、步长 S、填充 P 共同决定输出尺寸。
- **损失函数**：损失函数告诉模型“错在哪里”，优化器负责“怎么改参数”。
- **互相关**：CNN 训练会学习卷积核参数，因此互相关也能学到有效特征。

先用最普通的话说，**卷积** 就是：用小窗口在图像局部滑动，对局部像素和卷积核权重相乘求和，提取边缘、纹理等局部特征。

考试写到这里，最稳的一句话是：**输出尺寸：(输入尺寸 + 2P - K) / S + 1。**

这里最容易错的是：不要把 CNN 说成全连接；卷积核心是局部连接和参数共享。

### 2. 先讲 标准化

先用最普通的话说，**标准化** 就是：把数据按均值和方差调整到更稳定的尺度，帮助模型训练。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考归一化和标准化的区别、为什么图像输入要预处理。

这里最容易错的是：不要把标准化简单等同于除以 255；标准化通常涉及均值和标准差。

先用最普通的话说，**卷积核** 就是：卷积层中可学习的小矩阵/滤波器，用来扫描局部区域并提取特征。

先用最普通的话说，**归一化** 就是：把数值缩放到较统一范围，例如图像像素从 0-255 缩放到 0-1。

先用最普通的话说，**损失函数** 就是：把模型预测和真实标签之间的差距变成一个可优化的数值，反向传播就是从损失开始计算梯度。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考输出层与损失函数的匹配，例如多分类常配 CrossEntropyLoss，二分类可配 BCEWithLogitsLoss。

如果按课件顺序串起来，可以这样看：**学习率 -> 损失函数 -> Softmax**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**损失函数告诉模型“错在哪里”，优化器负责“怎么改参数”。**

这里最容易错的是：不要把准确率当作训练损失；也不要把 BCE 和 CE 的适用场景混用。

### 7. 先讲 Softmax

先用最普通的话说，**Softmax** 就是：把一组分数转成和为 1 的概率分布，常用于多分类或注意力权重。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考多分类输出、注意力权重为什么能加权求和。

如果按课件顺序串起来，可以这样看：**损失函数 -> Softmax -> 交叉熵**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**Softmax 输出非负且总和为 1。**

这里最容易错的是：Softmax 是对一组数整体归一化，不是逐个独立压缩。

### 8. 先讲 交叉熵

先用最普通的话说，**交叉熵** 就是：衡量预测概率分布与真实类别之间差距的分类损失。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考多分类用 CrossEntropyLoss，二分类/多标签用 BCE 类损失。

如果按课件顺序串起来，可以这样看：**Softmax -> 交叉熵 -> 卷积**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**交叉熵越小，预测分布越接近真实标签。**

这里最容易错的是：不要把交叉熵和准确率混成同一个东西。

### 9. 先讲 卷积

先用最普通的话说，**卷积** 就是：用小窗口在图像局部滑动，对局部像素和卷积核权重相乘求和，提取边缘、纹理等局部特征。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考输出尺寸、卷积核/步长/填充的作用，以及 CNN 实际常用互相关。

如果按课件顺序串起来，可以这样看：**交叉熵 -> 卷积 -> 互相关**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**输出尺寸：(输入尺寸 + 2P - K) / S + 1。**

这里最容易错的是：不要把 CNN 说成全连接；卷积核心是局部连接和参数共享。

### 10. 先讲 互相关

先用最普通的话说，**互相关** 就是：形式接近卷积，但不翻转卷积核；深度学习框架里的卷积层通常实际做互相关。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考 CNN 中是否需要翻转卷积核，或为什么工程上用互相关。

如果按课件顺序串起来，可以这样看：**卷积 -> 互相关 -> 后面的概念**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**CNN 训练会学习卷积核参数，因此互相关也能学到有效特征。**

这里最容易错的是：不要因为名字叫卷积层，就默认一定执行数学卷积的核翻转。

### 这一节最后怎么记

- **WeightedRandomSampler**：WeightedRandomSampler 调采样，不调损失。
- **类别不平衡**：类别不平衡要关注少数类召回等指标。
- **归一化**：图像常先把像素值缩放到 0-1。
- **标准化**：标准化常写作 (x-mean)/std。
- **学习率**：学习率决定更新步长。
- **损失函数**：损失函数告诉模型“错在哪里”，优化器负责“怎么改参数”。

### 本节检查题

1. **选择题：关于 WeightedRandomSampler，下列说法错误的是：**
   A. 按样本权重采样，常用于类别不平衡时提高少数类被抽到的概率。
   B. WeightedRandomSampler 调采样，不调损失。
   C. 常考它和 class weight、pos_weight 的区别。
   D. WeightedRandomSampler在 CNN 中通常用于增加全连接参数量，而不是保留图像结构。

   **答案：D。** A、B、C 都能和课件里的 WeightedRandomSampler 对上；D 是把概念说反或放错位置。

2. **资料题：** 材料中出现 类别不平衡，请判断它在本节属于数据、模型结构、训练优化还是输出目标，并说明理由。

   **参考答案：** 不同类别样本数量差距很大，模型容易偏向多数类。 答题时还要结合课件语境：常考采样、类别权重、pos_weight 等处理方式。

3. **简答题：为什么考试里不能只背 归一化 的定义？**

   **参考答案：** 因为 归一化 在课件中有明确的位置和作用：把数值缩放到较统一范围，例如图像像素从 0-255 缩放到 0-1。 答题时还要补出它通常怎么考：常考图像预处理为什么要缩放像素值。 最后要避开这个误区：归一化不等于 BatchNorm，前者多是输入预处理。

4. **辨析题：请区分 WeightedRandomSampler 和 标准化。**

   **参考答案：** WeightedRandomSampler：按样本权重采样，常用于类别不平衡时提高少数类被抽到的概率。；标准化：把数据按均值和方差调整到更稳定的尺度，帮助模型训练。。答题时先判断它们分别处在数据、结构、训练还是输出环节。
