读的时候先不要被代码吓到。你只需要先抓住：**前向传播得到预测，损失函数衡量错多少，反向传播算梯度，优化器改参数。**

## 开始按课件一点一点讲

## 第 1 部分：第三章 分类问题与多层感知机

### 这一节先不要急着背

这一节可以按 **Sigmoid -> Softmax -> 交叉熵 -> 多层感知机 -> Logistic** 的顺序读。第一个概念通常是入口，后面的概念要么是在补结构，要么是在解释训练时会遇到的问题。

### 1. 先讲 Sigmoid

先用最普通的话说，**Sigmoid** 就是：把任意实数压到 0 到 1 之间，可解释为概率或门控强度。GRU/LSTM 的门通常用它决定保留多少信息。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考输出范围、二分类概率、以及门控结构中为什么适合控制开关。

如果按课件顺序串起来，可以这样看：**前面的概念 -> Sigmoid -> Softmax**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**Sigmoid 输出在 0 到 1；越接近 1 越保留，越接近 0 越抑制。**

这里最容易错的是：Sigmoid 不只属于分类输出，在 RNN 门控里也很重要。

### 2. 先讲 Softmax

先用最普通的话说，**Softmax** 就是：把一组分数转成和为 1 的概率分布，常用于多分类或注意力权重。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考多分类输出、注意力权重为什么能加权求和。

如果按课件顺序串起来，可以这样看：**Sigmoid -> Softmax -> 交叉熵**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**Softmax 输出非负且总和为 1。**

这里最容易错的是：Softmax 是对一组数整体归一化，不是逐个独立压缩。

### 3. 先讲 交叉熵

先用最普通的话说，**交叉熵** 就是：衡量预测概率分布与真实类别之间差距的分类损失。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考多分类用 CrossEntropyLoss，二分类/多标签用 BCE 类损失。

如果按课件顺序串起来，可以这样看：**Softmax -> 交叉熵 -> 多层感知机**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**交叉熵越小，预测分布越接近真实标签。**

这里最容易错的是：不要把交叉熵和准确率混成同一个东西。

### 4. 先讲 多层感知机

先用最普通的话说，**多层感知机** 就是：多层感知机是由输入层、隐藏层和输出层组成的前馈神经网络。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考隐藏层作用、激活函数必要性、训练流程。

如果按课件顺序串起来，可以这样看：**交叉熵 -> 多层感知机 -> Logistic**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**多层感知机靠非线性激活增强表达能力。**

这里最容易错的是：多层感知机不是循环网络，也不保留时间状态。

### 5. 先讲 Logistic

先用最普通的话说，**Logistic** 就是：Logistic 回归常用于二分类，本质是线性输出接 Sigmoid 得到概率。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考二分类输出、Sigmoid、BCE 类损失的搭配。

如果按课件顺序串起来，可以这样看：**多层感知机 -> Logistic -> MLP**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**Logistic：线性打分 + Sigmoid。**

这里最容易错的是：Logistic 回归名字里有回归，但常用于分类。

### 6. 先讲 MLP

先用最普通的话说，**MLP** 就是：多层感知机由多层线性变换和非线性激活组成，是最基础的前馈神经网络。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考为什么需要激活函数、前向传播流程、分类输出和损失函数匹配。

如果按课件顺序串起来，可以这样看：**Logistic -> MLP -> 激活函数**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**MLP = 线性层 + 激活函数 + 输出层。**

这里最容易错的是：不要把多层线性层误认为天然具有非线性；没有激活函数仍等价于线性变换。

### 7. 先讲 激活函数

先用最普通的话说，**激活函数** 就是：给线性变换加入非线性，使网络能拟合非线性关系。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考没有激活函数时多层线性网络仍等价于线性模型。

如果按课件顺序串起来，可以这样看：**MLP -> 激活函数 -> 损失函数**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**仿射变换 + 激活函数 = 神经网络层的基本模式。**

这里最容易错的是：不要把激活函数说成只改变维度，它主要提供非线性。

### 8. 先讲 损失函数

先用最普通的话说，**损失函数** 就是：把模型预测和真实标签之间的差距变成一个可优化的数值，反向传播就是从损失开始计算梯度。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考输出层与损失函数的匹配，例如多分类常配 CrossEntropyLoss，二分类可配 BCEWithLogitsLoss。

如果按课件顺序串起来，可以这样看：**激活函数 -> 损失函数 -> BCEWithLogitsLoss**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**损失函数告诉模型“错在哪里”，优化器负责“怎么改参数”。**

这里最容易错的是：不要把准确率当作训练损失；也不要把 BCE 和 CE 的适用场景混用。

### 9. 先讲 BCEWithLogitsLoss

先用最普通的话说，**BCEWithLogitsLoss** 就是：二分类或多标签任务常用损失，内部把 Sigmoid 和 BCE 合在一起，数值更稳定。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考它输入的是 logits，不需要手动先做 Sigmoid。

如果按课件顺序串起来，可以这样看：**损失函数 -> BCEWithLogitsLoss -> CrossEntropyLoss**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**BCEWithLogitsLoss = Sigmoid + BCE。**

这里最容易错的是：不要在 BCEWithLogitsLoss 前再手动 Sigmoid。

### 10. 先讲 CrossEntropyLoss

先用最普通的话说，**CrossEntropyLoss** 就是：多分类常用损失，内部包含 LogSoftmax 和 NLLLoss。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考它输入 logits，标签通常是类别索引。

如果按课件顺序串起来，可以这样看：**BCEWithLogitsLoss -> CrossEntropyLoss -> 后面的概念**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**CrossEntropyLoss 用于单标签多分类。**

这里最容易错的是：不要在 CrossEntropyLoss 前手动 Softmax。

### 这一节最后怎么记

- **Sigmoid**：Sigmoid 输出在 0 到 1；越接近 1 越保留，越接近 0 越抑制。
- **Softmax**：Softmax 输出非负且总和为 1。
- **交叉熵**：交叉熵越小，预测分布越接近真实标签。
- **多层感知机**：多层感知机靠非线性激活增强表达能力。
- **Logistic**：Logistic：线性打分 + Sigmoid。
- **MLP**：MLP = 线性层 + 激活函数 + 输出层。

   A. 把任意实数压到 0 到 1 之间，可解释为概率或门控强度。GRU/LSTM 的门通常用它决定保留多少信息。
   B. Sigmoid 输出在 0 到 1；越接近 1 越保留，越接近 0 越抑制。
   C. 常考输出范围、二分类概率、以及门控结构中为什么适合控制开关。

   **参考答案：** Logistic 回归常用于二分类，本质是线性输出接 Sigmoid 得到概率。 答题时还要结合课件语境：常考二分类输出、Sigmoid、BCE 类损失的搭配。

3. **简答题：为什么考试里不能只背 Sigmoid 的定义？**

   **参考答案：** 因为 Sigmoid 在课件中有明确的位置和作用：把任意实数压到 0 到 1 之间，可解释为概率或门控强度。GRU/LSTM 的门通常用它决定保留多少信息。 答题时还要补出它通常怎么考：常考输出范围、二分类概率、以及门控结构中为什么适合控制开关。 最后要避开这个误区：Sigmoid 不只属于分类输出，在 RNN 门控里也很重要。

4. **辨析题：请区分 损失函数 和 Softmax。**

   **参考答案：** 损失函数：把模型预测和真实标签之间的差距变成一个可优化的数值，反向传播就是从损失开始计算梯度。；Softmax：把一组分数转成和为 1 的概率分布，常用于多分类或注意力权重。。答题时先判断它们分别处在数据、结构、训练还是输出环节。

## 第 6 部分：第三章 分类问题与多层感知机 / 第五节 多层感知机（MLP），也叫做全连接神经网络

### 这一节先不要急着背

这一节可以按 **激活函数 -> MLP -> Logistic -> 多层感知机 -> Sigmoid** 的顺序读。第一个概念通常是入口，后面的概念要么是在补结构，要么是在解释训练时会遇到的问题。

### 1. 先讲 激活函数

先用最普通的话说，**激活函数** 就是：给线性变换加入非线性，使网络能拟合非线性关系。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考没有激活函数时多层线性网络仍等价于线性模型。

如果按课件顺序串起来，可以这样看：**前面的概念 -> 激活函数 -> MLP**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**仿射变换 + 激活函数 = 神经网络层的基本模式。**

这里最容易错的是：不要把激活函数说成只改变维度，它主要提供非线性。

### 2. 先讲 MLP

先用最普通的话说，**MLP** 就是：多层感知机由多层线性变换和非线性激活组成，是最基础的前馈神经网络。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考为什么需要激活函数、前向传播流程、分类输出和损失函数匹配。

如果按课件顺序串起来，可以这样看：**激活函数 -> MLP -> Logistic**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**MLP = 线性层 + 激活函数 + 输出层。**

这里最容易错的是：不要把多层线性层误认为天然具有非线性；没有激活函数仍等价于线性变换。

### 3. 先讲 Logistic

先用最普通的话说，**Logistic** 就是：Logistic 回归常用于二分类，本质是线性输出接 Sigmoid 得到概率。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考二分类输出、Sigmoid、BCE 类损失的搭配。

如果按课件顺序串起来，可以这样看：**MLP -> Logistic -> 多层感知机**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**Logistic：线性打分 + Sigmoid。**

这里最容易错的是：Logistic 回归名字里有回归，但常用于分类。

### 4. 先讲 多层感知机

先用最普通的话说，**多层感知机** 就是：多层感知机是由输入层、隐藏层和输出层组成的前馈神经网络。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考隐藏层作用、激活函数必要性、训练流程。

如果按课件顺序串起来，可以这样看：**Logistic -> 多层感知机 -> Sigmoid**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**多层感知机靠非线性激活增强表达能力。**

这里最容易错的是：多层感知机不是循环网络，也不保留时间状态。

### 5. 先讲 Sigmoid

先用最普通的话说，**Sigmoid** 就是：把任意实数压到 0 到 1 之间，可解释为概率或门控强度。GRU/LSTM 的门通常用它决定保留多少信息。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考输出范围、二分类概率、以及门控结构中为什么适合控制开关。

如果按课件顺序串起来，可以这样看：**多层感知机 -> Sigmoid -> 梯度消失**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**Sigmoid 输出在 0 到 1；越接近 1 越保留，越接近 0 越抑制。**

这里最容易错的是：Sigmoid 不只属于分类输出，在 RNN 门控里也很重要。

### 6. 先讲 梯度消失

先用最普通的话说，**梯度消失** 就是：反向传播经过很多层或很多时间步时，梯度可能不断变小，导致前面层或早期时间步很难学到东西。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考深层网络/RNN 为什么训练困难，以及 LSTM、GRU、残差连接如何缓解。

如果按课件顺序串起来，可以这样看：**Sigmoid -> 梯度消失 -> 仿射变换**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**多个小于 1 的因子连乘，会让梯度趋近 0。**

这里最容易错的是：梯度消失不是过拟合；它是参数难以有效更新的问题。

### 7. 先讲 仿射变换

先用最普通的话说，**仿射变换** 就是：线性加权求和再加偏置，常写作 Wx+b。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考它和激活函数的配合：仿射变换本身仍是线性结构。

如果按课件顺序串起来，可以这样看：**梯度消失 -> 仿射变换 -> 后面的概念**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**仿射变换：Wx+b。**

这里最容易错的是：不要把仿射变换本身说成非线性映射。

### 这一节最后怎么记

- **激活函数**：仿射变换 + 激活函数 = 神经网络层的基本模式。
- **MLP**：MLP = 线性层 + 激活函数 + 输出层。
- **Logistic**：Logistic：线性打分 + Sigmoid。
- **多层感知机**：多层感知机靠非线性激活增强表达能力。
- **Sigmoid**：Sigmoid 输出在 0 到 1；越接近 1 越保留，越接近 0 越抑制。
- **梯度消失**：多个小于 1 的因子连乘，会让梯度趋近 0。
