---

## 先说整份课件到底在解决什么问题

这一份课件要解决的是：**当数据本身是一张图时，模型怎样同时利用节点特征和节点之间的关系。**

图学习最重要的不是某个模型名字，而是“对象之间有边，边决定信息怎么传”。GNN 的很多方法都可以看成邻居信息的聚合和更新。

读的时候先抓这条线：**节点/边 -> 邻接矩阵 -> 图任务类型 -> 随机游走或表示学习 -> GCN/GAT 等图神经网络。**

## 开始按课件一点一点讲

## 第 1 部分：图卷积网络（GCN）

### 这一节先不要急着背

这一节可以按 **图卷积 -> GCN -> 节点 -> 邻接矩阵 -> 度矩阵** 的顺序读。第一个概念通常是入口，后面的概念要么是在补结构，要么是在解释训练时会遇到的问题。

### 1. 先讲 图卷积

先用最普通的话说，**图卷积** 就是：把卷积思想扩展到图结构，通过邻居聚合更新节点表示。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考它和图像卷积的不同：邻域由图边决定。

如果按课件顺序串起来，可以这样看：**前面的概念 -> 图卷积 -> GCN**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**图卷积的邻域来自图结构。**

这里最容易错的是：不要把图卷积理解成固定方形卷积核在图上滑动。

### 2. 先讲 GCN

先用最普通的话说，**GCN** 就是：图卷积网络，通过邻接关系聚合邻居节点特征，再更新节点表示。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考 GCN 为什么能利用图结构、聚合邻居信息的基本流程。

如果按课件顺序串起来，可以这样看：**图卷积 -> GCN -> 节点**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**GCN：邻居聚合 + 线性变换 + 非线性。**

这里最容易错的是：GCN 不只看节点自身特征，还看邻居。

### 3. 先讲 节点

先用最普通的话说，**节点** 就是：图中的对象或实体，可以带有节点特征。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考节点分类任务：预测每个节点的类别。

如果按课件顺序串起来，可以这样看：**GCN -> 节点 -> 邻接矩阵**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**节点表示对象，边表示对象之间的关系。**

这里最容易错的是：节点特征和边关系是两类信息，不要混在一起。

### 4. 先讲 邻接矩阵

先用最普通的话说，**邻接矩阵** 就是：用矩阵记录节点之间是否相连或连接权重。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考根据图画矩阵，或根据矩阵判断邻居。

如果按课件顺序串起来，可以这样看：**节点 -> 邻接矩阵 -> 度矩阵**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**A_ij 表示 i 到 j 是否有边或边权。**

这里最容易错的是：无向图邻接矩阵通常对称；有向图不一定对称。

### 5. 先讲 度矩阵

先用最普通的话说，**度矩阵** 就是：对角矩阵，对角线记录每个节点的度。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常和拉普拉斯矩阵 L=D-A 一起考。

如果按课件顺序串起来，可以这样看：**邻接矩阵 -> 度矩阵 -> 后面的概念**。
也就是说，你不是在背一个词，而是在看知识点之间怎样往下推进。

考试写到这里，最稳的一句话是：**D_ii = 节点 i 的度。**

这里最容易错的是：度矩阵不是邻接矩阵，它只放在对角线上。

### 这一节最后怎么记

- **图卷积**：图卷积的邻域来自图结构。
- **GCN**：GCN：邻居聚合 + 线性变换 + 非线性。
- **节点**：节点表示对象，边表示对象之间的关系。
- **邻接矩阵**：A_ij 表示 i 到 j 是否有边或边权。
- **度矩阵**：D_ii = 节点 i 的度。

### 本节检查题

1. **选择题：关于 图卷积，下列说法错误的是：**
   A. 把卷积思想扩展到图结构，通过邻居聚合更新节点表示。
   B. 图卷积的邻域来自图结构。
   C. 常考它和图像卷积的不同：邻域由图边决定。
   D. 图卷积只处理单个节点特征，不需要考虑边或邻居。

   **答案：D。** A、B、C 都能和课件里的 图卷积 对上；D 是把概念说反或放错位置。

2. **资料题：** 材料中出现 GCN，请判断它在本节属于数据、模型结构、训练优化还是输出目标，并说明理由。

   **参考答案：** 图卷积网络，通过邻接关系聚合邻居节点特征，再更新节点表示。 答题时还要结合课件语境：常考 GCN 为什么能利用图结构、聚合邻居信息的基本流程。

3. **简答题：为什么考试里不能只背 节点 的定义？**

   **参考答案：** 因为 节点 在课件中有明确的位置和作用：图中的对象或实体，可以带有节点特征。 答题时还要补出它通常怎么考：常考节点分类任务：预测每个节点的类别。 最后要避开这个误区：节点特征和边关系是两类信息，不要混在一起。

4. **辨析题：请区分 图卷积 和 邻接矩阵。**

   **参考答案：** 图卷积：把卷积思想扩展到图结构，通过邻居聚合更新节点表示。；邻接矩阵：用矩阵记录节点之间是否相连或连接权重。。答题时先判断它们分别处在数据、结构、训练还是输出环节。

   C. 常考输出范围、二分类概率、以及门控结构中为什么适合控制开关。
   D. Sigmoid 的输出范围可以小于 0 或大于 1。

   **答案：D。** A、B、C 都能和课件里的 Sigmoid 对上；D 是把概念说反或放错位置。

## 第 11 部分：训练过程

### 这一节先不要急着背

这一节先集中理解 **Batch**。不要一上来背定义，先问：课件为什么在这里讲它？它补上了前面哪一个问题？

### 1. 先讲 Batch

先用最普通的话说，**Batch** 就是：一次送入模型并一起计算损失的一组样本。它决定每次参数更新看到多少样本，也影响显存占用和训练稳定性。

它在这份课件里不是孤立出现的。你要把它理解成这一节用来解决问题的一块拼图：常考 batch size、mini-batch、epoch、iteration 的区别，也会结合张量形状中的 N 维度判断。

考试写到这里，最稳的一句话是：**Batch 是一批样本；Epoch 是全训练集完整训练一遍。**

这里最容易错的是：Batch 不是序列长度；在 RNN 中常见形状里 N 是样本数，L 才是时间步长度。

### 这一节最后怎么记

- **Batch**：Batch 是一批样本；Epoch 是全训练集完整训练一遍。

### 本节检查题

1. **选择题：关于 Batch，下列说法错误的是：**
   A. 一次送入模型并一起计算损失的一组样本。它决定每次参数更新看到多少样本，也影响显存占用和训练稳定性。
   B. Batch 是一批样本；Epoch 是全训练集完整训练一遍。
   C. 常考 batch size、mini-batch、epoch、iteration 的区别，也会结合张量形状中的 N 维度判断。
   D. Batch 表示序列长度，而不是一次送入模型的样本数。

   **答案：D。** A、B、C 都能和课件里的 Batch 对上；D 是把概念说反或放错位置。
