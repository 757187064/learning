## 第五章 神经网络训练技巧深度解析
### 学习率
- 通俗解释：控制每次参数沿梯度方向更新的步子大小。学习率太大容易震荡甚至发散，太小则收敛很慢。
- 考试怎么考：常考学习率过大/过小的训练现象，以及学习率调度的目的。
- 易错点：学习率不是越大越好；也不是模型学到的参数。
- 必记：学习率决定更新步长。
### 梯度消失
- 通俗解释：反向传播经过很多层或很多时间步时，梯度可能不断变小，导致前面层或早期时间步很难学到东西。
- 考试怎么考：常考深层网络/RNN 为什么训练困难，以及 LSTM、GRU、残差连接如何缓解。
- 易错点：梯度消失不是过拟合；它是参数难以有效更新的问题。
- 必记：多个小于 1 的因子连乘，会让梯度趋近 0。
### 梯度爆炸
- 通俗解释：梯度在反向传播中变得过大，使参数更新剧烈，训练损失可能震荡或变成 NaN。
- 考试怎么考：常考梯度裁剪为什么能缓解 RNN 训练不稳定。
- 易错点：Dropout 主要缓解过拟合，不是解决梯度爆炸的标准答案。
- 必记：梯度裁剪限制梯度范数，防止更新步子过大。
### 优化器
- 通俗解释：根据梯度和自身规则更新模型参数。
- 考试怎么考：常考 SGD、Momentum、RMSProp、Adam 的区别。
- 易错点：优化器不是损失函数；损失给目标，优化器改参数。
- 必记：优化器负责执行参数更新。
### 超参数
- 通俗解释：训练前人为设定的配置，如学习率、batch size、层数、dropout 比例。
- 考试怎么考：常考它和模型参数的区别。
- 易错点：超参数不是通过反向传播直接学出来的参数。
- 必记：超参数先设定，模型参数训练中学习。
### 损失函数
- 通俗解释：把模型预测和真实标签之间的差距变成一个可优化的数值，反向传播就是从损失开始计算梯度。
- 考试怎么考：常考输出层与损失函数的匹配，例如多分类常配 CrossEntropyLoss，二分类可配 BCEWithLogitsLoss。
- 易错点：不要把准确率当作训练损失；也不要把 BCE 和 CE 的适用场景混用。
- 必记：损失函数告诉模型“错在哪里”，优化器负责“怎么改参数”。
### Batch
- 通俗解释：一次送入模型并一起计算损失的一组样本。它决定每次参数更新看到多少样本，也影响显存占用和训练稳定性。
- 考试怎么考：常考 batch size、mini-batch、epoch、iteration 的区别，也会结合张量形状中的 N 维度判断。
- 易错点：Batch 不是序列长度；在 RNN 中常见形状里 N 是样本数，L 才是时间步长度。
- 必记：Batch 是一批样本；Epoch 是全训练集完整训练一遍。
### Sigmoid
- 通俗解释：把任意实数压到 0 到 1 之间，可解释为概率或门控强度。GRU/LSTM 的门通常用它决定保留多少信息。
- 考试怎么考：常考输出范围、二分类概率、以及门控结构中为什么适合控制开关。
- 易错点：Sigmoid 不只属于分类输出，在 RNN 门控里也很重要。
- 必记：Sigmoid 输出在 0 到 1；越接近 1 越保留，越接近 0 越抑制。
### 激活函数
- 通俗解释：给线性变换加入非线性，使网络能拟合非线性关系。
- 考试怎么考：常考没有激活函数时多层线性网络仍等价于线性模型。
- 易错点：不要把激活函数说成只改变维度，它主要提供非线性。
- 必记：仿射变换 + 激活函数 = 神经网络层的基本模式。
### 卷积
- 通俗解释：用小窗口在图像局部滑动，对局部像素和卷积核权重相乘求和，提取边缘、纹理等局部特征。
- 考试怎么考：常考输出尺寸、卷积核/步长/填充的作用，以及 CNN 实际常用互相关。
- 易错点：不要把 CNN 说成全连接；卷积核心是局部连接和参数共享。
- 必记：输出尺寸：(输入尺寸 + 2P - K) / S + 1。

### 梯度裁剪
- 通俗解释：当梯度范数超过阈值时按比例缩小，常用于稳定 RNN 等容易梯度爆炸的训练。

- 易错点：裁剪不是把梯度直接清零，而是限制其大小。
- 必记：Gradient Clipping：限制梯度大小，稳定训练。

### 反向传播
- 通俗解释：从损失函数出发，按链式法则把梯度传回各层参数。
- 考试怎么考：常考它和前向传播、损失函数、优化器的顺序关系。
- 易错点：反向传播只负责算梯度，真正改参数的是优化器。
- 必记：前向算预测，损失算错误，反向算梯度。
### 标准化
- 通俗解释：把数据按均值和方差调整到更稳定的尺度，帮助模型训练。
- 考试怎么考：常考归一化和标准化的区别、为什么图像输入要预处理。
- 易错点：不要把标准化简单等同于除以 255；标准化通常涉及均值和标准差。
- 必记：标准化常写作 (x-mean)/std。
## 第五章 神经网络训练技巧深度解析 / 第2节 优化器改进与学习率调整
### 学习率
- 通俗解释：控制每次参数沿梯度方向更新的步子大小。学习率太大容易震荡甚至发散，太小则收敛很慢。
- 考试怎么考：常考学习率过大/过小的训练现象，以及学习率调度的目的。
- 易错点：学习率不是越大越好；也不是模型学到的参数。
- 必记：学习率决定更新步长。
### Adam
- 通俗解释：结合动量和自适应学习率思想，为不同参数调整更新幅度。
- 考试怎么考：常和 SGD、Momentum、RMSProp 对比优化器特点。
- 易错点：Adam 方便但不等于一定泛化最好，仍需调学习率等超参数。
- 必记：Adam = 一阶动量 + 二阶矩估计。
### 优化器
- 通俗解释：根据梯度和自身规则更新模型参数。
- 考试怎么考：常考 SGD、Momentum、RMSProp、Adam 的区别。
- 易错点：优化器不是损失函数；损失给目标，优化器改参数。
- 必记：优化器负责执行参数更新。
### RMSProp
- 通俗解释：用梯度平方的指数滑动平均调整学习率，缓解 Adagrad 学习率过快衰减。
- 考试怎么考：常考它和 Adagrad 的区别。
- 易错点：不要写成简单固定学习率下降。
- 必记：RMSProp 使用指数滑动平均保存近期梯度尺度。
### Momentum
- 通俗解释：在梯度下降中加入历史更新方向，让更新更平滑、减少震荡。
- 考试怎么考：常考它为什么能加速或稳定训练。
- 易错点：Momentum 不是学习率本身，而是利用历史梯度趋势。
- 必记：Momentum 像给梯度下降加惯性。
### 梯度下降
- 通俗解释：沿着损失函数下降最快的方向调整参数，让模型预测逐步变好。
- 考试怎么考：常考参数更新方向、学习率作用、训练循环位置。
- 易错点：梯度下降不是直接调准确率，而是通过损失函数和梯度改参数。
- 必记：参数更新方向通常与梯度相反。
### ResNet
- 通俗解释：用残差/跳跃连接让网络学习 F(x)+x，缓解深层网络退化和梯度传播困难。
- 考试怎么考：常考残差连接为什么能训练更深网络。
- 易错点：残差连接不是单纯增加层数，而是改变信息和梯度路径。
- 必记：ResNet 核心：y = F(x) + x。
### Epoch
- 通俗解释：训练集被模型完整看过一遍，叫一个 epoch。一个 epoch 内通常包含很多个 batch 更新。
- 考试怎么考：常考 Epoch、Batch、Iteration 的区别，或判断训练轮数增加对欠拟合/过拟合的影响。
- 易错点：Epoch 不是一次参数更新；一次更新通常对应一个 batch。
- 必记：1 个 Epoch = 全部训练样本被用过一遍。
### 梯度消失
- 通俗解释：反向传播经过很多层或很多时间步时，梯度可能不断变小，导致前面层或早期时间步很难学到东西。
- 考试怎么考：常考深层网络/RNN 为什么训练困难，以及 LSTM、GRU、残差连接如何缓解。
- 易错点：梯度消失不是过拟合；它是参数难以有效更新的问题。
- 必记：多个小于 1 的因子连乘，会让梯度趋近 0。
### 步长
- 通俗解释：卷积核或池化窗口每次移动的间隔。
- 考试怎么考：常考步长变大时输出尺寸如何变化。
- 易错点：步长越大，输出空间尺寸通常越小。
- 必记：Stride 控制滑动间隔。
## 第五章 神经网络训练技巧深度解析 / 第3节 处理过拟合的综合策略
### Dropout
- 通俗解释：训练时随机丢弃一部分神经元，迫使网络不要过度依赖某些特征。
- 考试怎么考：常考训练阶段启用、推理阶段关闭，以及它缓解过拟合。
- 易错点：Dropout 不是提高模型容量，而是正则化。
- 必记：Dropout：训练随机失活，推理正常使用。
### 数据增强
- 通俗解释：对训练数据做随机变换，增加样本多样性，缓解过拟合。
- 考试怎么考：常考图像翻转、裁剪、颜色扰动等增强方法。
- 易错点：数据增强通常只用于训练集，不应破坏标签含义。
- 必记：数据增强让模型见到更多合理变化。
### 卷积
- 通俗解释：用小窗口在图像局部滑动，对局部像素和卷积核权重相乘求和，提取边缘、纹理等局部特征。
- 考试怎么考：常考输出尺寸、卷积核/步长/填充的作用，以及 CNN 实际常用互相关。
- 易错点：不要把 CNN 说成全连接；卷积核心是局部连接和参数共享。
- 必记：输出尺寸：(输入尺寸 + 2P - K) / S + 1。
### 权重衰减
- 通俗解释：通过惩罚过大的权重来正则化模型，常用于缓解过拟合。
- 考试怎么考：常考它和 L2 正则化、过拟合控制的关系。
- 易错点：不要把权重衰减当成学习率衰减。
- 必记：权重衰减限制参数过大。
### 损失函数
- 通俗解释：把模型预测和真实标签之间的差距变成一个可优化的数值，反向传播就是从损失开始计算梯度。

- 易错点：不要把准确率当作训练损失；也不要把 BCE 和 CE 的适用场景混用。
- 必记：损失函数告诉模型“错在哪里”，优化器负责“怎么改参数”。
### Epoch
- 通俗解释：训练集被模型完整看过一遍，叫一个 epoch。一个 epoch 内通常包含很多个 batch 更新。
- 考试怎么考：常考 Epoch、Batch、Iteration 的区别，或判断训练轮数增加对欠拟合/过拟合的影响。
- 易错点：Epoch 不是一次参数更新；一次更新通常对应一个 batch。
- 必记：1 个 Epoch = 全部训练样本被用过一遍。
### 交叉熵
- 通俗解释：衡量预测概率分布与真实类别之间差距的分类损失。
- 考试怎么考：常考多分类用 CrossEntropyLoss，二分类/多标签用 BCE 类损失。
- 易错点：不要把交叉熵和准确率混成同一个东西。
- 必记：交叉熵越小，预测分布越接近真实标签。

### 归一化
- 通俗解释：把数值缩放到较统一范围，例如图像像素从 0-255 缩放到 0-1。
- 考试怎么考：常考图像预处理为什么要缩放像素值。
- 易错点：归一化不等于 BatchNorm，前者多是输入预处理。
- 必记：图像常先把像素值缩放到 0-1。
### Momentum
- 通俗解释：在梯度下降中加入历史更新方向，让更新更平滑、减少震荡。
- 考试怎么考：常考它为什么能加速或稳定训练。
- 易错点：Momentum 不是学习率本身，而是利用历史梯度趋势。
- 必记：Momentum 像给梯度下降加惯性。
### 超参数
- 通俗解释：训练前人为设定的配置，如学习率、batch size、层数、dropout 比例。
- 考试怎么考：常考它和模型参数的区别。
- 易错点：超参数不是通过反向传播直接学出来的参数。
- 必记：超参数先设定，模型参数训练中学习。
