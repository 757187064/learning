# 循环神经网络-学生分发版-终版2026 / 总览
## 第五章 循环神经网络
### GRU
- 通俗解释：用更新门和重置门控制历史信息保留与遗忘，是简化版门控循环网络。
- 考试怎么考：常和 LSTM 对比门结构和参数量。
- 易错点：GRU 没有单独的细胞状态 c_t。
- 必记：GRU：更新门 + 重置门。
### LSTM
- 通俗解释：通过输入门、遗忘门、输出门和细胞状态保存长期信息。
- 考试怎么考：常考门控作用，以及为什么能缓解长序列梯度问题。
- 易错点：不要漏掉细胞状态是 LSTM 的关键通道。
- 必记：LSTM：输入门、遗忘门、输出门、细胞状态。
### Padding
- 通俗解释：把不同长度的序列补到同一长度，方便组成 batch 输入模型。
- 考试怎么考：常考为什么需要 padding，以及它和 packing 的关系。
- 易错点：Padding 补出来的位置不是真实信息，训练时要避免把它当有效时间步。
- 必记：Padding：补齐长度；Packing：跳过无效补位。
### Packing
- 通俗解释：把变长序列的有效部分打包，让 RNN 少处理 padding 位置。
- 考试怎么考：常考 pack_padded_sequence 的目的和使用前提。
- 易错点：Packing 不是改变序列含义，而是提高变长序列处理效率。
- 必记：Packing 让 RNN 聚焦真实时间步。
### 1D卷积
- 通俗解释：在序列的一维时间/位置方向上滑动卷积核，提取局部 n-gram 或短期模式。
- 考试怎么考：常和 RNN 对比：1D 卷积并行提取局部模式，RNN 逐步传递隐藏状态。
- 易错点：1D 卷积适合局部依赖，不等于天然拥有长期记忆。
- 必记：1D 卷积：沿序列维度提取局部模式。
## 第五章 循环神经网络 / 第一节 序列数据与循环神经网络
### 隐藏状态
- 通俗解释：RNN 在每个时间步保存的当前记忆，用来把历史信息传给后续时间步。
- 考试怎么考：常考 h_t 与 h_{t-1} 的关系，以及 output 和 h_n 的区别。
- 易错点：隐藏状态不是模型参数，而是随输入序列变化的中间表示。
- 必记：h_t = 当前输入 + 过去记忆的综合表示。
### 双向RNN
- 通俗解释：同时从前往后和从后往前读序列，让当前位置利用左右两侧上下文。
- 考试怎么考：常考它为什么比单向 RNN 能看到更多上下文。
- 易错点：双向 RNN 不适合严格只能用过去信息的实时预测场景。
- 必记：双向 RNN = 正向隐藏状态 + 反向隐藏状态。
### RNN
- 通俗解释：按时间步处理序列，用隐藏状态把前面信息传到后面。
- 考试怎么考：常考隐藏状态、序列建模、梯度消失/爆炸。
- 易错点：RNN 不是一次性把所有时间步完全独立处理。
- 必记：当前输出依赖当前输入和上一时刻隐藏状态。
### 激活函数
- 通俗解释：给线性变换加入非线性，使网络能拟合非线性关系。
- 考试怎么考：常考没有激活函数时多层线性网络仍等价于线性模型。
- 易错点：不要把激活函数说成只改变维度，它主要提供非线性。
- 必记：仿射变换 + 激活函数 = 神经网络层的基本模式。
### 梯度消失
- 通俗解释：反向传播经过很多层或很多时间步时，梯度可能不断变小，导致前面层或早期时间步很难学到东西。
- 考试怎么考：常考深层网络/RNN 为什么训练困难，以及 LSTM、GRU、残差连接如何缓解。
- 易错点：梯度消失不是过拟合；它是参数难以有效更新的问题。
- 必记：多个小于 1 的因子连乘，会让梯度趋近 0。
### 堆叠RNN
- 通俗解释：把多层 RNN 叠起来，上一层的输出序列作为下一层输入。
- 考试怎么考：常考堆叠带来更强表达能力，也增加训练难度。
- 易错点：堆叠不是时间步变多，而是层数变深。
- 必记：堆叠 RNN：时间方向 + 层方向都要传播。
### 损失函数
- 通俗解释：把模型预测和真实标签之间的差距变成一个可优化的数值，反向传播就是从损失开始计算梯度。
- 考试怎么考：常考输出层与损失函数的匹配，例如多分类常配 CrossEntropyLoss，二分类可配 BCEWithLogitsLoss。
- 易错点：不要把准确率当作训练损失；也不要把 BCE 和 CE 的适用场景混用。
- 必记：损失函数告诉模型“错在哪里”，优化器负责“怎么改参数”。
### Padding
- 通俗解释：把不同长度的序列补到同一长度，方便组成 batch 输入模型。
- 考试怎么考：常考为什么需要 padding，以及它和 packing 的关系。
- 易错点：Padding 补出来的位置不是真实信息，训练时要避免把它当有效时间步。
- 必记：Padding：补齐长度；Packing：跳过无效补位。
### Dropout
- 通俗解释：训练时随机丢弃一部分神经元，迫使网络不要过度依赖某些特征。
- 考试怎么考：常考训练阶段启用、推理阶段关闭，以及它缓解过拟合。
- 易错点：Dropout 不是提高模型容量，而是正则化。
- 必记：Dropout：训练随机失活，推理正常使用。
### Seq2Seq
- 通俗解释：编码器把输入序列压成表示，解码器再生成输出序列，常用于翻译、问答等序列到序列任务。
- 考试怎么考：常考 Encoder-Decoder 结构、Teacher Forcing 和注意力机制为何被引入。
- 易错点：普通 Seq2Seq 容易受固定长度上下文瓶颈影响。
- 必记：Seq2Seq = Encoder + Decoder。
## 第五章 循环神经网络 / 第二节 门控循环单元（GRU）

- 考试怎么考：常考输出范围、二分类概率、以及门控结构中为什么适合控制开关。
- 易错点：Sigmoid 不只属于分类输出，在 RNN 门控里也很重要。
- 必记：Sigmoid 输出在 0 到 1；越接近 1 越保留，越接近 0 越抑制。

- 必记：仿射变换 + 激活函数 = 神经网络层的基本模式。
### GRU

- 考试怎么考：常和 LSTM 对比门结构和参数量。

## 第五章 循环神经网络 / 第四节 变长序列处理：Padding与Packing
### Padding
- 通俗解释：把不同长度的序列补到同一长度，方便组成 batch 输入模型。
- 考试怎么考：常考为什么需要 padding，以及它和 packing 的关系。
- 易错点：Padding 补出来的位置不是真实信息，训练时要避免把它当有效时间步。
- 必记：Padding：补齐长度；Packing：跳过无效补位。
### Packing
- 通俗解释：把变长序列的有效部分打包，让 RNN 少处理 padding 位置。
- 考试怎么考：常考 pack_padded_sequence 的目的和使用前提。
- 易错点：Packing 不是改变序列含义，而是提高变长序列处理效率。
- 必记：Packing 让 RNN 聚焦真实时间步。
### 隐藏状态
- 通俗解释：RNN 在每个时间步保存的当前记忆，用来把历史信息传给后续时间步。
- 考试怎么考：常考 h_t 与 h_{t-1} 的关系，以及 output 和 h_n 的区别。
- 易错点：隐藏状态不是模型参数，而是随输入序列变化的中间表示。
- 必记：h_t = 当前输入 + 过去记忆的综合表示。
### Batch
- 通俗解释：一次送入模型并一起计算损失的一组样本。它决定每次参数更新看到多少样本，也影响显存占用和训练稳定性。
- 考试怎么考：常考 batch size、mini-batch、epoch、iteration 的区别，也会结合张量形状中的 N 维度判断。
- 易错点：Batch 不是序列长度；在 RNN 中常见形状里 N 是样本数，L 才是时间步长度。
- 必记：Batch 是一批样本；Epoch 是全训练集完整训练一遍。
### PackedSequence
- 通俗解释：PyTorch 中表示变长序列打包后的对象，内部只保留有效时间步，交给 RNN 处理时可以跳过 padding。
- 考试怎么考：常考 pack_padded_sequence 与 pad_packed_sequence 的前后关系。
- 易错点：PackedSequence 不是普通张量；使用前后要注意 lengths、batch_first 和是否排序。
- 必记：先 padding 组成 batch，再 packing 跳过补位，必要时再 pad 回来。
## 第五章 循环神经网络 / 第五节 1D卷积在序列数据上的应用
### 卷积
- 通俗解释：用小窗口在图像局部滑动，对局部像素和卷积核权重相乘求和，提取边缘、纹理等局部特征。
- 考试怎么考：常考输出尺寸、卷积核/步长/填充的作用，以及 CNN 实际常用互相关。
- 易错点：不要把 CNN 说成全连接；卷积核心是局部连接和参数共享。
- 必记：输出尺寸：(输入尺寸 + 2P - K) / S + 1。
### 感受野
- 通俗解释：某一层一个神经元能看到原始输入图像的区域大小。
- 考试怎么考：常考层数、卷积核大小、步长如何影响感受野。
- 易错点：步长变大通常会让前一层对应感受野扩大，不是缩小。
- 必记：层越深，感受野通常越大；多层小卷积能逐步扩大感受野。
### 1D卷积
- 通俗解释：在序列的一维时间/位置方向上滑动卷积核，提取局部 n-gram 或短期模式。

### TCN
- 通俗解释：时间卷积网络，用一维卷积建模序列，常用因果卷积和扩张卷积扩大感受野。
- 考试怎么考：常和 RNN 对比并行性和长期依赖建模方式。
- 易错点：TCN 不是循环结构，不靠隐藏状态逐步传递。
- 必记：TCN 用卷积处理序列。
### 卷积核
- 通俗解释：卷积层中可学习的小矩阵/滤波器，用来扫描局部区域并提取特征。
- 考试怎么考：常考卷积核大小、通道数、参数共享和输出尺寸计算。
- 易错点：卷积核参数会训练更新，不是手工固定模板。

## 第五章 循环神经网络 / 第六节 PyTorch实现综合案例
### Dropout
- 通俗解释：训练时随机丢弃一部分神经元，迫使网络不要过度依赖某些特征。
- 考试怎么考：常考训练阶段启用、推理阶段关闭，以及它缓解过拟合。
- 易错点：Dropout 不是提高模型容量，而是正则化。
- 必记：Dropout：训练随机失活，推理正常使用。
### 学习率
- 通俗解释：控制每次参数沿梯度方向更新的步子大小。学习率太大容易震荡甚至发散，太小则收敛很慢。
- 考试怎么考：常考学习率过大/过小的训练现象，以及学习率调度的目的。
- 易错点：学习率不是越大越好；也不是模型学到的参数。
- 必记：学习率决定更新步长。
### 梯度爆炸
- 通俗解释：梯度在反向传播中变得过大，使参数更新剧烈，训练损失可能震荡或变成 NaN。
- 考试怎么考：常考梯度裁剪为什么能缓解 RNN 训练不稳定。
- 易错点：Dropout 主要缓解过拟合，不是解决梯度爆炸的标准答案。
- 必记：梯度裁剪限制梯度范数，防止更新步子过大。
### 梯度裁剪
- 通俗解释：当梯度范数超过阈值时按比例缩小，常用于稳定 RNN 等容易梯度爆炸的训练。
- 考试怎么考：常考它处理的是梯度爆炸，而不是梯度消失。
- 易错点：裁剪不是把梯度直接清零，而是限制其大小。
- 必记：Gradient Clipping：限制梯度大小，稳定训练。
### Adam
- 通俗解释：结合动量和自适应学习率思想，为不同参数调整更新幅度。
- 考试怎么考：常和 SGD、Momentum、RMSProp 对比优化器特点。
- 易错点：Adam 方便但不等于一定泛化最好，仍需调学习率等超参数。
- 必记：Adam = 一阶动量 + 二阶矩估计。
### Batch
- 通俗解释：一次送入模型并一起计算损失的一组样本。它决定每次参数更新看到多少样本，也影响显存占用和训练稳定性。
- 考试怎么考：常考 batch size、mini-batch、epoch、iteration 的区别，也会结合张量形状中的 N 维度判断。
- 易错点：Batch 不是序列长度；在 RNN 中常见形状里 N 是样本数，L 才是时间步长度。
- 必记：Batch 是一批样本；Epoch 是全训练集完整训练一遍。
### Sigmoid
- 通俗解释：把任意实数压到 0 到 1 之间，可解释为概率或门控强度。GRU/LSTM 的门通常用它决定保留多少信息。
- 考试怎么考：常考输出范围、二分类概率、以及门控结构中为什么适合控制开关。
- 易错点：Sigmoid 不只属于分类输出，在 RNN 门控里也很重要。
- 必记：Sigmoid 输出在 0 到 1；越接近 1 越保留，越接近 0 越抑制。
### 隐藏状态
- 通俗解释：RNN 在每个时间步保存的当前记忆，用来把历史信息传给后续时间步。
- 考试怎么考：常考 h_t 与 h_{t-1} 的关系，以及 output 和 h_n 的区别。
- 易错点：隐藏状态不是模型参数，而是随输入序列变化的中间表示。
- 必记：h_t = 当前输入 + 过去记忆的综合表示。
### LSTM
- 通俗解释：通过输入门、遗忘门、输出门和细胞状态保存长期信息。
- 考试怎么考：常考门控作用，以及为什么能缓解长序列梯度问题。
- 易错点：不要漏掉细胞状态是 LSTM 的关键通道。
- 必记：LSTM：输入门、遗忘门、输出门、细胞状态。
### Padding
- 通俗解释：把不同长度的序列补到同一长度，方便组成 batch 输入模型。
- 考试怎么考：常考为什么需要 padding，以及它和 packing 的关系。
- 易错点：Padding 补出来的位置不是真实信息，训练时要避免把它当有效时间步。
- 必记：Padding：补齐长度；Packing：跳过无效补位。
