## 第四章 卷积神经网络基础与入门实践
### 卷积
- 通俗解释：用小窗口在图像局部滑动，对局部像素和卷积核权重相乘求和，提取边缘、纹理等局部特征。
- 考试怎么考：常考输出尺寸、卷积核/步长/填充的作用，以及 CNN 实际常用互相关。
- 易错点：不要把 CNN 说成全连接；卷积核心是局部连接和参数共享。
- 必记：输出尺寸：(输入尺寸 + 2P - K) / S + 1。
### 感受野
- 通俗解释：某一层一个神经元能看到原始输入图像的区域大小。
- 考试怎么考：常考层数、卷积核大小、步长如何影响感受野。
- 易错点：步长变大通常会让前一层对应感受野扩大，不是缩小。
- 必记：层越深，感受野通常越大；多层小卷积能逐步扩大感受野。
### 池化
- 通俗解释：对局部区域做最大值或平均值汇总，降低空间尺寸并增强一定平移不变性。
- 考试怎么考：常考池化作用、是否有可学习参数、与卷积的区别。
- 易错点：池化不是全连接，也不是用来增加参数量。
- 必记：池化：降采样、压缩空间尺寸、保留显著信息。
### 卷积核
- 通俗解释：卷积层中可学习的小矩阵/滤波器，用来扫描局部区域并提取特征。
- 考试怎么考：常考卷积核大小、通道数、参数共享和输出尺寸计算。
- 易错点：卷积核参数会训练更新，不是手工固定模板。
- 必记：卷积核大小 K、步长 S、填充 P 共同决定输出尺寸。
### 损失函数
- 通俗解释：把模型预测和真实标签之间的差距变成一个可优化的数值，反向传播就是从损失开始计算梯度。
- 考试怎么考：常考输出层与损失函数的匹配，例如多分类常配 CrossEntropyLoss，二分类可配 BCEWithLogitsLoss。
- 易错点：不要把准确率当作训练损失；也不要把 BCE 和 CE 的适用场景混用。
- 必记：损失函数告诉模型“错在哪里”，优化器负责“怎么改参数”。
### 互相关
- 通俗解释：形式接近卷积，但不翻转卷积核；深度学习框架里的卷积层通常实际做互相关。
- 考试怎么考：常考 CNN 中是否需要翻转卷积核，或为什么工程上用互相关。
- 易错点：不要因为名字叫卷积层，就默认一定执行数学卷积的核翻转。
- 必记：CNN 训练会学习卷积核参数，因此互相关也能学到有效特征。
### Valid
- 通俗解释：不填充边界，只在卷积核完全落入输入时计算，输出尺寸会变小。
- 考试怎么考：常和 Same、Full 对比考输出大小。
- 易错点：Valid 不是大量填充，恰好是不填充。
- 必记：Valid：无填充，输出通常最小。
### Same
- 通俗解释：通过适当填充，让卷积输出空间尺寸尽量和输入保持一致。
- 考试怎么考：常考给定输入、卷积核、步长时需要多少 padding。
- 易错点：Same 的目标是保持尺寸，不是扩大特征图。
- 必记：步长为 1 时，Same 卷积常让 H、W 不变。
### Full
- 通俗解释：在边界外进行更充分的填充，使卷积核可以覆盖到输入边缘外侧，输出会变大。
- 考试怎么考：常和 Valid、Same 放在一起判断哪种输出最大。
- 易错点：Full 不是常规 CNN 默认选择，考试多用于概念区分。
- 必记：Full：充分填充，输出通常最大。
### NCHW
- 通俗解释：图像张量格式，依次表示 Batch、Channel、Height、Width，PyTorch 中很常见。
- 考试怎么考：常考 NCHW 与 NHWC 的维度顺序，以及卷积层输入通道位置。
- 易错点：不要把 Channel 和 Height/Width 顺序写反。
- 必记：NCHW = Batch, Channel, Height, Width。

## 第四章 卷积神经网络基础与入门实践 / 第2节 图像表示与通道概念
### 卷积
- 通俗解释：用小窗口在图像局部滑动，对局部像素和卷积核权重相乘求和，提取边缘、纹理等局部特征。
- 考试怎么考：常考输出尺寸、卷积核/步长/填充的作用，以及 CNN 实际常用互相关。
- 易错点：不要把 CNN 说成全连接；卷积核心是局部连接和参数共享。
- 必记：输出尺寸：(输入尺寸 + 2P - K) / S + 1。
### 标准化
- 通俗解释：把数据按均值和方差调整到更稳定的尺度，帮助模型训练。
- 考试怎么考：常考归一化和标准化的区别、为什么图像输入要预处理。
- 易错点：不要把标准化简单等同于除以 255；标准化通常涉及均值和标准差。
- 必记：标准化常写作 (x-mean)/std。
### 卷积核
- 通俗解释：卷积层中可学习的小矩阵/滤波器，用来扫描局部区域并提取特征。
- 考试怎么考：常考卷积核大小、通道数、参数共享和输出尺寸计算。
- 易错点：卷积核参数会训练更新，不是手工固定模板。
- 必记：卷积核大小 K、步长 S、填充 P 共同决定输出尺寸。
### 激活函数
- 通俗解释：给线性变换加入非线性，使网络能拟合非线性关系。
- 考试怎么考：常考没有激活函数时多层线性网络仍等价于线性模型。
- 易错点：不要把激活函数说成只改变维度，它主要提供非线性。
- 必记：仿射变换 + 激活函数 = 神经网络层的基本模式。
### 归一化
- 通俗解释：把数值缩放到较统一范围，例如图像像素从 0-255 缩放到 0-1。
- 考试怎么考：常考图像预处理为什么要缩放像素值。
- 易错点：归一化不等于 BatchNorm，前者多是输入预处理。
- 必记：图像常先把像素值缩放到 0-1。
### Batch
- 通俗解释：一次送入模型并一起计算损失的一组样本。它决定每次参数更新看到多少样本，也影响显存占用和训练稳定性。
- 考试怎么考：常考 batch size、mini-batch、epoch、iteration 的区别，也会结合张量形状中的 N 维度判断。
- 易错点：Batch 不是序列长度；在 RNN 中常见形状里 N 是样本数，L 才是时间步长度。
- 必记：Batch 是一批样本；Epoch 是全训练集完整训练一遍。
### 梯度下降
- 通俗解释：沿着损失函数下降最快的方向调整参数，让模型预测逐步变好。
- 考试怎么考：常考参数更新方向、学习率作用、训练循环位置。
- 易错点：梯度下降不是直接调准确率，而是通过损失函数和梯度改参数。
- 必记：参数更新方向通常与梯度相反。
### NCHW
- 通俗解释：图像张量格式，依次表示 Batch、Channel、Height、Width，PyTorch 中很常见。
- 考试怎么考：常考 NCHW 与 NHWC 的维度顺序，以及卷积层输入通道位置。
- 易错点：不要把 Channel 和 Height/Width 顺序写反。
- 必记：NCHW = Batch, Channel, Height, Width。
### NHWC
- 通俗解释：图像张量格式，依次表示 Batch、Height、Width、Channel。
- 考试怎么考：常和 NCHW 对比考框架数据格式。
- 易错点：不要把 NHWC 当成 PyTorch 卷积层默认输入格式。
- 必记：NHWC = Batch, Height, Width, Channel。
### 数据增强
- 通俗解释：对训练数据做随机变换，增加样本多样性，缓解过拟合。
- 考试怎么考：常考图像翻转、裁剪、颜色扰动等增强方法。
- 易错点：数据增强通常只用于训练集，不应破坏标签含义。
- 必记：数据增强让模型见到更多合理变化。

## 第四章 卷积神经网络基础与入门实践 / 第4节 网络配置与损失函数应匹配
### 交叉熵
- 通俗解释：衡量预测概率分布与真实类别之间差距的分类损失。
- 考试怎么考：常考多分类用 CrossEntropyLoss，二分类/多标签用 BCE 类损失。
- 易错点：不要把交叉熵和准确率混成同一个东西。
- 必记：交叉熵越小，预测分布越接近真实标签。
### 损失函数
- 通俗解释：把模型预测和真实标签之间的差距变成一个可优化的数值，反向传播就是从损失开始计算梯度。
- 考试怎么考：常考输出层与损失函数的匹配，例如多分类常配 CrossEntropyLoss，二分类可配 BCEWithLogitsLoss。
- 易错点：不要把准确率当作训练损失；也不要把 BCE 和 CE 的适用场景混用。
- 必记：损失函数告诉模型“错在哪里”，优化器负责“怎么改参数”。
### BCEWithLogitsLoss
- 通俗解释：二分类或多标签任务常用损失，内部把 Sigmoid 和 BCE 合在一起，数值更稳定。
- 考试怎么考：常考它输入的是 logits，不需要手动先做 Sigmoid。
- 易错点：不要在 BCEWithLogitsLoss 前再手动 Sigmoid。
- 必记：BCEWithLogitsLoss = Sigmoid + BCE。
### CrossEntropyLoss
- 通俗解释：多分类常用损失，内部包含 LogSoftmax 和 NLLLoss。
- 考试怎么考：常考它输入 logits，标签通常是类别索引。
- 易错点：不要在 CrossEntropyLoss 前手动 Softmax。
- 必记：CrossEntropyLoss 用于单标签多分类。
### 类别不平衡
- 通俗解释：不同类别样本数量差距很大，模型容易偏向多数类。
- 考试怎么考：常考采样、类别权重、pos_weight 等处理方式。
- 易错点：准确率高不一定说明少数类学得好。
- 必记：类别不平衡要关注少数类召回等指标。
### Sigmoid
- 通俗解释：把任意实数压到 0 到 1 之间，可解释为概率或门控强度。GRU/LSTM 的门通常用它决定保留多少信息。
- 考试怎么考：常考输出范围、二分类概率、以及门控结构中为什么适合控制开关。
- 易错点：Sigmoid 不只属于分类输出，在 RNN 门控里也很重要。
- 必记：Sigmoid 输出在 0 到 1；越接近 1 越保留，越接近 0 越抑制。
### Softmax
- 通俗解释：把一组分数转成和为 1 的概率分布，常用于多分类或注意力权重。
- 考试怎么考：常考多分类输出、注意力权重为什么能加权求和。
- 易错点：Softmax 是对一组数整体归一化，不是逐个独立压缩。
- 必记：Softmax 输出非负且总和为 1。
### 激活函数
- 通俗解释：给线性变换加入非线性，使网络能拟合非线性关系。
- 考试怎么考：常考没有激活函数时多层线性网络仍等价于线性模型。
- 易错点：不要把激活函数说成只改变维度，它主要提供非线性。
- 必记：仿射变换 + 激活函数 = 神经网络层的基本模式。
### 归一化
- 通俗解释：把数值缩放到较统一范围，例如图像像素从 0-255 缩放到 0-1。
- 考试怎么考：常考图像预处理为什么要缩放像素值。

## 第四章 卷积神经网络基础与入门实践 / 第5节 PyTorch实现CNN图像分类（完整流程）
### WeightedRandomSampler
- 通俗解释：按样本权重采样，常用于类别不平衡时提高少数类被抽到的概率。
- 考试怎么考：常考它和 class weight、pos_weight 的区别。
- 易错点：它改变采样概率，不直接改变损失函数公式。
- 必记：WeightedRandomSampler 调采样，不调损失。
### 类别不平衡
- 通俗解释：不同类别样本数量差距很大，模型容易偏向多数类。
- 考试怎么考：常考采样、类别权重、pos_weight 等处理方式。
- 易错点：准确率高不一定说明少数类学得好。
- 必记：类别不平衡要关注少数类召回等指标。
### 归一化
- 通俗解释：把数值缩放到较统一范围，例如图像像素从 0-255 缩放到 0-1。
- 考试怎么考：常考图像预处理为什么要缩放像素值。
- 易错点：归一化不等于 BatchNorm，前者多是输入预处理。
- 必记：图像常先把像素值缩放到 0-1。
### 标准化
- 通俗解释：把数据按均值和方差调整到更稳定的尺度，帮助模型训练。
- 考试怎么考：常考归一化和标准化的区别、为什么图像输入要预处理。
- 易错点：不要把标准化简单等同于除以 255；标准化通常涉及均值和标准差。
- 必记：标准化常写作 (x-mean)/std。
### 学习率
- 通俗解释：控制每次参数沿梯度方向更新的步子大小。学习率太大容易震荡甚至发散，太小则收敛很慢。
- 考试怎么考：常考学习率过大/过小的训练现象，以及学习率调度的目的。
- 易错点：学习率不是越大越好；也不是模型学到的参数。
- 必记：学习率决定更新步长。
### 损失函数
- 通俗解释：把模型预测和真实标签之间的差距变成一个可优化的数值，反向传播就是从损失开始计算梯度。
- 考试怎么考：常考输出层与损失函数的匹配，例如多分类常配 CrossEntropyLoss，二分类可配 BCEWithLogitsLoss。
- 易错点：不要把准确率当作训练损失；也不要把 BCE 和 CE 的适用场景混用。
- 必记：损失函数告诉模型“错在哪里”，优化器负责“怎么改参数”。
### Softmax
- 通俗解释：把一组分数转成和为 1 的概率分布，常用于多分类或注意力权重。
- 考试怎么考：常考多分类输出、注意力权重为什么能加权求和。
- 易错点：Softmax 是对一组数整体归一化，不是逐个独立压缩。
- 必记：Softmax 输出非负且总和为 1。
### 交叉熵
- 通俗解释：衡量预测概率分布与真实类别之间差距的分类损失。
- 考试怎么考：常考多分类用 CrossEntropyLoss，二分类/多标签用 BCE 类损失。
- 易错点：不要把交叉熵和准确率混成同一个东西。
- 必记：交叉熵越小，预测分布越接近真实标签。
### 卷积
- 通俗解释：用小窗口在图像局部滑动，对局部像素和卷积核权重相乘求和，提取边缘、纹理等局部特征。
- 考试怎么考：常考输出尺寸、卷积核/步长/填充的作用，以及 CNN 实际常用互相关。
- 易错点：不要把 CNN 说成全连接；卷积核心是局部连接和参数共享。
- 必记：输出尺寸：(输入尺寸 + 2P - K) / S + 1。
### 互相关
- 通俗解释：形式接近卷积，但不翻转卷积核；深度学习框架里的卷积层通常实际做互相关。
- 考试怎么考：常考 CNN 中是否需要翻转卷积核，或为什么工程上用互相关。
- 易错点：不要因为名字叫卷积层，就默认一定执行数学卷积的核翻转。
- 必记：CNN 训练会学习卷积核参数，因此互相关也能学到有效特征。
