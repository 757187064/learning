## 第四章 卷积神经网络基础与入门实践 / 第4节 网络配置与损失函数应匹配
### 交叉熵
- 通俗解释：衡量预测概率分布与真实类别之间差距的分类损失。
- 考试怎么考：常考多分类用 CrossEntropyLoss，二分类/多标签用 BCE 类损失。
- 易错点：不要把交叉熵和准确率混成同一个东西。
- 必记：交叉熵越小，预测分布越接近真实标签。
### 损失函数
- 通俗解释：把模型预测和真实标签之间的差距变成一个可优化的数值，反向传播就是从损失开始计算梯度。
- 考试怎么考：常考输出层与损失函数的匹配，例如多分类常配 CrossEntropyLoss，二分类可配 BCEWithLogitsLoss。
- 易错点：不要把准确率当作训练损失；也不要把 BCE 和 CE 的适用场景混用。
- 必记：损失函数告诉模型“错在哪里”，优化器负责“怎么改参数”。
### BCEWithLogitsLoss
- 通俗解释：二分类或多标签任务常用损失，内部把 Sigmoid 和 BCE 合在一起，数值更稳定。
- 考试怎么考：常考它输入的是 logits，不需要手动先做 Sigmoid。
- 易错点：不要在 BCEWithLogitsLoss 前再手动 Sigmoid。
- 必记：BCEWithLogitsLoss = Sigmoid + BCE。
### CrossEntropyLoss
- 通俗解释：多分类常用损失，内部包含 LogSoftmax 和 NLLLoss。
- 考试怎么考：常考它输入 logits，标签通常是类别索引。
- 易错点：不要在 CrossEntropyLoss 前手动 Softmax。
- 必记：CrossEntropyLoss 用于单标签多分类。
### 类别不平衡
- 通俗解释：不同类别样本数量差距很大，模型容易偏向多数类。
- 考试怎么考：常考采样、类别权重、pos_weight 等处理方式。
- 易错点：准确率高不一定说明少数类学得好。
- 必记：类别不平衡要关注少数类召回等指标。
### Sigmoid
- 通俗解释：把任意实数压到 0 到 1 之间，可解释为概率或门控强度。GRU/LSTM 的门通常用它决定保留多少信息。
- 考试怎么考：常考输出范围、二分类概率、以及门控结构中为什么适合控制开关。
- 易错点：Sigmoid 不只属于分类输出，在 RNN 门控里也很重要。
- 必记：Sigmoid 输出在 0 到 1；越接近 1 越保留，越接近 0 越抑制。
### Softmax
- 通俗解释：把一组分数转成和为 1 的概率分布，常用于多分类或注意力权重。
- 考试怎么考：常考多分类输出、注意力权重为什么能加权求和。
- 易错点：Softmax 是对一组数整体归一化，不是逐个独立压缩。
- 必记：Softmax 输出非负且总和为 1。
### 激活函数
- 通俗解释：给线性变换加入非线性，使网络能拟合非线性关系。
- 考试怎么考：常考没有激活函数时多层线性网络仍等价于线性模型。
- 易错点：不要把激活函数说成只改变维度，它主要提供非线性。
- 必记：仿射变换 + 激活函数 = 神经网络层的基本模式。
### 归一化
- 通俗解释：把数值缩放到较统一范围，例如图像像素从 0-255 缩放到 0-1。
- 考试怎么考：常考图像预处理为什么要缩放像素值。
- 易错点：归一化不等于 BatchNorm，前者多是输入预处理。
- 必记：图像常先把像素值缩放到 0-1。
### WeightedRandomSampler
- 通俗解释：按样本权重采样，常用于类别不平衡时提高少数类被抽到的概率。
- 考试怎么考：常考它和 class weight、pos_weight 的区别。
- 易错点：它改变采样概率，不直接改变损失函数公式。
- 必记：WeightedRandomSampler 调采样，不调损失。
