## 第一梯队 1：神经元、TLU、感知机、ADALINE

这部分是课程最早的导学内容，用来说明神经网络不是凭空出现的，而是从阈值逻辑、线性分类和误差更新一路发展出来。

### 先抓主线

- **TLU 阈值逻辑单元**：把多个输入加权求和，再和阈值比较，输出 0 或 1，是早期神经元模型的抽象形式。
- **逻辑门**：AND、OR、NOT 可以用不同权重和阈值的 TLU 表示，说明简单神经元能模拟基本布尔逻辑。
- **构造性合成**：先用第一层识别若干输入模式，再用后一层把模式合并，从而构造更复杂的布尔函数。
- **感知机**：感知机是带权重和偏置的线性分类器，通过符号判断把输入分到超平面两侧。
- **ADALINE**：ADALINE 使用连续线性输出计算误差，更自然地引出损失函数、梯度下降和参数更新。

### 考试怎么写

- TLU 阈值逻辑单元：常考权重、阈值、阶跃函数分别起什么作用，以及它为什么只能形成线性边界。 易错点：不要把 TLU 说成能直接表达所有非线性逻辑；XOR 是典型反例。
- 逻辑门：常考给定权重和阈值判断它对应哪个逻辑门，或解释为什么 XOR 需要多层组合。 易错点：不要把能表示 AND/OR 推成能单层表示任意逻辑。
- 构造性合成：常考多层结构为什么比单层 TLU 表达能力更强。 易错点：不要只说层数变多；关键是隐藏层能表示中间模式。
- 感知机：常考线性可分、决策边界、XOR 局限。 易错点：单层感知机只能处理线性可分问题。
- ADALINE：常考它和感知机的区别：训练时关注连续误差，而不是只看阶跃后的类别。 易错点：不要把 ADALINE 完全等同于感知机的二值输出学习。

### 必背句

- TLU = 加权求和 + 阈值判断 + 二值输出。
- 基本逻辑门可由 TLU 实现，复杂逻辑通常需要组合。
- 多层网络可以先识别局部模式，再组合成最终输出。
- 感知机决策边界是线性的。
- ADALINE 把神经元学习和误差最小化连接起来。

### 题型提醒

单选题常把“单层感知机能否解决 XOR”“ADALINE 是否只看阶跃输出”说反；简答题要写出从 TLU 到感知机再到 ADALINE 的递进。

## 第一梯队 2：训练流程与 MLP

MLP 是后面所有模型的训练基础。你要把数据、模型、输出、损失、反向传播、参数更新连成闭环，而不是孤立背函数名。

### 先抓主线

- **损失函数**：把模型预测和真实标签之间的差距变成一个可优化的数值，反向传播就是从损失开始计算梯度。
- **反向传播**：从损失函数出发，按链式法则把梯度传回各层参数。
- **激活函数**：给线性变换加入非线性，使网络能拟合非线性关系。
- **梯度下降**：沿着损失函数下降最快的方向调整参数，让模型预测逐步变好。
- **激活函数**：给线性变换加入非线性，使网络能拟合非线性关系。

### 考试怎么写

- 损失函数：常考输出层与损失函数的匹配，例如多分类常配 CrossEntropyLoss，二分类可配 BCEWithLogitsLoss。 易错点：不要把准确率当作训练损失；也不要把 BCE 和 CE 的适用场景混用。
- 反向传播：常考它和前向传播、损失函数、优化器的顺序关系。 易错点：反向传播只负责算梯度，真正改参数的是优化器。
- 激活函数：常考没有激活函数时多层线性网络仍等价于线性模型。 易错点：不要把激活函数说成只改变维度，它主要提供非线性。
- 梯度下降：常考参数更新方向、学习率作用、训练循环位置。 易错点：梯度下降不是直接调准确率，而是通过损失函数和梯度改参数。
- 激活函数：常考没有激活函数时多层线性网络仍等价于线性模型。 易错点：不要把激活函数说成只改变维度，它主要提供非线性。

### 必背句

- 损失函数告诉模型“错在哪里”，优化器负责“怎么改参数”。
- 前向算预测，损失算错误，反向算梯度。
- 仿射变换 + 激活函数 = 神经网络层的基本模式。
- 参数更新方向通常与梯度相反。
- 仿射变换 + 激活函数 = 神经网络层的基本模式。

### 题型提醒

资料题可能给一段 PyTorch 训练代码，让你指出缺少 zero_grad、loss.backward、optimizer.step 或损失函数输入错误。

## 第一梯队 3：CNN 与图像建模

CNN 的核心动机是图像有空间结构，不能像普通表格一样随便展平。局部连接、参数共享、卷积核、池化和感受野是整章骨架。

### 先抓主线

- **卷积**：用小窗口在图像局部滑动，对局部像素和卷积核权重相乘求和，提取边缘、纹理等局部特征。
- **感受野**：某一层一个神经元能看到原始输入图像的区域大小。
- **池化**：对局部区域做最大值或平均值汇总，降低空间尺寸并增强一定平移不变性。
- **卷积核**：卷积层中可学习的小矩阵/滤波器，用来扫描局部区域并提取特征。
- **损失函数**：把模型预测和真实标签之间的差距变成一个可优化的数值，反向传播就是从损失开始计算梯度。

### 考试怎么写

- 卷积：常考输出尺寸、卷积核/步长/填充的作用，以及 CNN 实际常用互相关。 易错点：不要把 CNN 说成全连接；卷积核心是局部连接和参数共享。
- 感受野：常考层数、卷积核大小、步长如何影响感受野。 易错点：步长变大通常会让前一层对应感受野扩大，不是缩小。
- 池化：常考池化作用、是否有可学习参数、与卷积的区别。 易错点：池化不是全连接，也不是用来增加参数量。
- 卷积核：常考卷积核大小、通道数、参数共享和输出尺寸计算。 易错点：卷积核参数会训练更新，不是手工固定模板。
- 损失函数：常考输出层与损失函数的匹配，例如多分类常配 CrossEntropyLoss，二分类可配 BCEWithLogitsLoss。 易错点：不要把准确率当作训练损失；也不要把 BCE 和 CE 的适用场景混用。

### 必背句

- 输出尺寸：(输入尺寸 + 2P - K) / S + 1。
- 层越深，感受野通常越大；多层小卷积能逐步扩大感受野。
- 池化：降采样、压缩空间尺寸、保留显著信息。
- 卷积核大小 K、步长 S、填充 P 共同决定输出尺寸。
- 损失函数告诉模型“错在哪里”，优化器负责“怎么改参数”。

### 题型提醒

单选题常考输出尺寸、Same/Valid/Full、互相关、池化是否有参数；简答题要能比较 MLP 处理图像和 CNN 的差别。

## 第一梯队 5：Attention 与 Transformer

Transformer 的主线是用注意力直接建立序列位置之间的联系。Q/K/V、softmax 权重、mask、位置编码和多头注意力要连起来看。

### 先抓主线

- **Transformer**：以注意力为核心的序列模型，用多头注意力、前馈网络、残差和归一化堆叠编码器/解码器。
- **RNN**：按时间步处理序列，用隐藏状态把前面信息传到后面。
- **Seq2Seq**：编码器把输入序列压成表示，解码器再生成输出序列，常用于翻译、问答等序列到序列任务。
- **Attention**：根据相关性分配权重，再对信息加权汇总。
- **注意力机制**：根据 Query 与 Key 的匹配程度，给 Value 分配权重并加权求和。

### 考试怎么写

- Transformer：常考编码器/解码器结构、多头注意力和位置编码。 易错点：Transformer 不依赖 RNN 的逐步递归来建模序列。
- RNN：常考隐藏状态、序列建模、梯度消失/爆炸。 易错点：RNN 不是一次性把所有时间步完全独立处理。
- Seq2Seq：常考 Encoder-Decoder 结构、Teacher Forcing 和注意力机制为何被引入。 易错点：普通 Seq2Seq 容易受固定长度上下文瓶颈影响。
- Attention：常考 Q/K/V、权重、softmax、上下文向量。 易错点：Attention 不是简单平均。
- 注意力机制：常考 Q/K/V 含义、注意力权重、上下文向量计算流程。 易错点：注意力不是简单平均，而是按相关性加权。

### 必背句

- Transformer 核心：Attention + FFN + 残差 + Norm + 位置编码。
- 当前输出依赖当前输入和上一时刻隐藏状态。
- Seq2Seq = Encoder + Decoder。
- Attention = 按相关性加权关注。
- Attention(Q,K,V)=softmax(QK^T/sqrt(d_k))V。

### 题型提醒

单选题常把 Q/K/V 角色、sqrt(d_k)、Target Mask 和 Source Mask 混淆；简答题要能写出注意力公式流程。

## 三类题型作答方法

### 单选题

先判断题干问“正确”还是“错误”。常见错误选项有四类：把概念放错流程位置、把训练/推理说反、把输入输出形状说反、把模型作用夸大成万能。

### 简答题

推荐四句式：第一句写定义，第二句写作用，第三句写在模型或训练流程中的位置，第四句写一个易错点或与相近概念的区别。

### 资料题

先圈材料中的任务类型、输入数据、模型结构、损失/训练配置，再回答问题。不要先背定义；资料题考的是你能否把定义放回具体情境。

## 考前最后一遍

- 神经元/MLP：会解释线性、非线性、激活函数、损失函数匹配。
- CNN：会算输出尺寸，会说清局部连接、参数共享、池化、感受野。
- RNN：会说隐藏状态、GRU/LSTM 门控、padding/packing。
- Transformer：会写 Q/K/V 流程、mask、位置编码、多头注意力。
- GNN/LLM/PINN/材料科学：抓“为什么需要它”和“它利用了什么结构或先验”。
